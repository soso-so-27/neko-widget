この共有仕様は、招待した少人数だけの限定外部TestFlightベータとして確認中です。App Storeで一般提供している版ではありません。

この限定外部TestFlight共有ベータの初期版では、1台のiPhoneで合計3個までの名前付き非公開なまどを作成・参加・切り替えでき、設定中のまどは同時に1個です。以前のBuildや機種変更との互換性のため、端末内の保存形式は最大20個を保持でき、既存のまどが3個を超えていても削除・非表示にはしません。1つのまどは作成者と信頼できる招待相手1人だけで使います。各参加者は、承認した最大4台のiPhoneで同じまどを使えます。家族に限定しません。公開フィード、検索、フォロー、匿名の出会いはありません。

公開の問い合わせに、写真、招待コード、12語の確認フレーズ、暗号鍵、氏名・住所・メールアドレスなどの個人情報を投稿しないでください。

問い合わせ方法

TestFlightで試している場合

TestFlightの「ベータ版フィードバックを送信」を利用してください。この経路は外部テスターから開発者へ非公開で届きます。スクリーンショットを添付する前に、写真、招待コード、確認フレーズが写っていないか確認してください。

技術的な不具合・一般的な質問

公開サポート窓口（GitHub Issues）へ、アプリのBuild番号、iOSバージョン、iPhone機種、再現手順だけを記載してください。公開してよい情報だけを送ってください。

受信写真の安全上の問題

この1人限定の外部TestFlightでは、新規の暗号化通報受付は停止しています。アプリ内通報は利用できず、写真や通報用暗号文は送信・保存されません。

まず受信写真の安全メニューで「この相手をブロック」を選び、確認画面の「ブロックしてまどを解除」で新しい送受信を止めてください。その後、TestFlightの「ベータ版フィードバックを送信」から問題の概要とBuild番号だけを連絡してください。写真、招待コード、12語の確認フレーズ、暗号鍵は添付しないでください。

よくある確認

ペアリングだけのBuild

画面に「ペアリングのみ」「写真を保存・送信しません」と表示されるBuildでは、写真共有を試すことはできません。これは故障ではありません。

写真共有が有効なBuild

  1. 両端末で同じ12語を順番どおり確認してから承認する。
  2. iPhoneの「設定」からSensitive Content Warningを有効にする。
  3. まど画面の「写真を選んで届ける」から一枚を選ぶ。写真アプリの共有シートで一枚を開き、「ねこのまど」に一時保存する方法も利用できます。
  4. 確認画面で送り先、写真、安全確認を見てから送信し、送信状況を確認する。
  5. 通知を許可したBuildでは、写真またはハートのサーバー受付後に一般的な新着通知が届く場合があります。通知を開くと対象のまど・写真を照合します。変化がない場合は該当するまどを開き、エラー画面に「もう一度確認する」が表示されたときだけ押してください。

通知は写真や相手名を含まず、到着時刻はAppleとiOSの制御を受けます。iOS 18を含め、アプリを閉じた状態のWidget更新はbest effortです。通知が届いてもWidgetがすぐ更新されない場合は、通知を開くかアプリの「状態を更新」を使用してください。アプリを強制終了した状態では、次にアプリを開くまで背景更新されない場合があります。

同じiCloud写真を使う2台でも、非公開なまどの鍵と状態は端末ごとに分かれます。試験中に写真の経路を区別したい場合は、写真ライブラリへ保存せず、送信端末だけにあるスクリーンショットを共有してください。iCloudからサインアウトしたり写真を削除したりする必要はありません。

届いた写真の「思い出」

操作していない「届いた写真」は、このiPhone内で最長90日、最大500枚、256MiBまでの一時的な受信履歴です。

受信写真の「思い出に残す」を明示的に選ぶと、位置情報を除いた最大2,048pxの写真を写真アプリへ保存し、通常の「思い出」と写真まとめに加えます。相手には通知しません。iCloud写真がオンの場合はAppleと端末の設定に従って同期されます。「思い出から外す」、共有解除、ブロック、アプリ削除のあとも写真アプリには残り、本アプリから写真そのものは削除しません。ハートを送っただけでは保存しません。

「思い出」の写真を書き出す

「思い出」に残した一枚のメニューから「写真を書き出す」を選ぶと、位置情報、撮影日時、元のファイル名などの元情報を除いた長辺2,048px以下のJPEGを作成し、iOSの共有シートを開きます。アプリ自身が管理する書き出し用の一時ファイルは作らず、開発者のサーバーへ自動送信しません。共有先は利用者が選び、そのサービスとポリシーが適用されます。iOSまたは共有先が画像のコピーを作成・保持する場合があります。

共有解除とデータ

設定の「共有の設定・解除」から解除できます。再インストール後は古い共有鍵を復元せず、再招待が必要です。相手がすでに「思い出に残す」で写真アプリへ保存した写真やスクリーンショットは、解除後も本サービスから削除できません。詳しくはプライバシーポリシーをご覧ください。

応答時間

安全上のTestFlightフィードバックは原則48時間以内に初回確認します。一般的な技術問い合わせは順次確認します。この窓口は緊急通報先ではありません。生命・身体への差し迫った危険は地域の緊急窓口へ連絡してください。

English summary

Each app installation can keep up to 20 named private windows. Each window is shared only by its creator and one trusted invitee. Each participant can use up to four approved iPhone installations for that window. The app has no public feed, search, following, or anonymous discovery. When the user explicitly exports one saved Memory photo, the app passes an in-memory JPEG up to 2,048px with location and source metadata removed to the iOS share sheet; the selected destination's policy applies and may retain a copy. Encrypted in-app report ingestion is disabled for this one-person external TestFlight. Block the sender to end sharing and use Send Beta Feedback without attaching the photo or any invitation secret. For non-sensitive technical questions, use the public GitHub Issues link above.
