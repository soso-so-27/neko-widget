ねこのまどの使い方と、困ったときの連絡先です。写真や個人の情報は、公開の場所に書かないでください。

困ったとき

猫の写真が見つからない

猫の写真を撮ってから、もう一度アプリを開いてください。「一部を選択」にしているときは、「写真を追加で選ぶ」で猫の写真を足せます。写真が多いと、見分けるのに少し時間がかかります。アプリを開いたままにすると進みます。

猫ではない写真が出る

写真を開いて「…」→「猫の写真から外す」を押すと、その写真は出なくなります。写真アプリの写真は消えません。

外した写真を戻したい

設定の「写真の表示と整理」→「外した写真」で「戻す」を押します。設定は「この子」タブの右上から開きます。

ホーム画面のウィジェットに写真が出ない・変わらない

変わらないときは、ウィジェットを編集して「ねこのまど」の設定を確かめ、アプリを一度開いてください。切り替わる時刻はiOSが決めるので、操作の直後には変わらないことがあります。

くもりのまどが晴れない

ウィジェットの「タップで、きょうの1枚」の札を押すと晴れます。ほかの場所を押すとアプリが開くだけで、くもりは残ります。

猫を10匹より多く登録したい・名前が入らない

猫は10匹まで登録できます。名前は20字までです。

まどに入れない

1つのまどに入れるのは6人まで、1人が使えるiPhoneは3台までです。招待リンクは24時間使えます。過ぎたときは、招待した人に新しいリンクを送ってもらってください。

Plusが「確認できません」と出る

もう一度購入せずに、設定の「購入を復元」を押してください。

自動保存で番号（P01など）が出た

記録は消えていません。その番号を、お問い合わせで伝えてください。

まどに写真が届かない

届けるには、まどを作った人がPlusを使っている必要があります（招待された人は無料です）。1つのまどに届けられるのは、1人1日5枚までです。通知を許可していれば、届いたときに知らせます。

届いた写真はいつまで見られる

1つのまどにつき新しいものから500枚まで、そのiPhoneの中に残ります。残したい写真は、写真アプリに保存してください。

家族の手帳が止まっている

Plusを使っていた人が家族から抜けたか、その人のPlusを確かめられていません。新しく書いたことが家族に届かないだけで、それまでの記録は消えません。抜けたときは、家族の中でPlusのある人が手帳の「わたしのPlusで再開する」を押すか、だれかがPlusを始めると戻ります。Plusを確かめられないときは、確かめられると自動で戻ります。

作品がとどかない

その月に猫の写真が5枚ほどないと、作品はできません。通知が来ないときは、iPhoneの「設定」→「ねこのまど」→「通知」を確かめてください。

機種変更するには

Plusの自動保存を使っていれば、新しいiPhoneでサインインすると、自分の記録と写真が自動保存から戻ります。家族と共有している手帳は、新しいiPhoneで家族にもう一度招待してもらうと戻ります。自分で足した証明の写真は、招待の前でも「この子のこと」で開けます。まどには、新しいiPhoneでもう一度招待を受けて参加してください（鍵はiPhoneごとに作るためです）。

家族が入れない

ねこのまどは、iOS 17.1以上のiPhoneで使えます。それより前のiPhoneには入れられません。

Plusを解約するには

iPhoneの「設定」→ 自分の名前 →「サブスクリプション」→「ねこのまど」。解約しても、写真・まど・メモは消えません。止まるのは、新しく増えるものだけです。自動保存のコピーだけは、購読の終わりから12か月後に消えます（消す前に知らせます）。

困った相手がいる

まどの写真の「…」から、通報とブロックができます。ブロックすると、その相手からの写真は届かなくなります。通報すると通報番号が出るので、問い合わせのときに書いてください。

お問い合わせ

support@nekonomado.com

  • 書いてほしいこと：iPhoneの機種、iOSのバージョン、アプリのバージョン（設定の下にあります）、何をしたらどうなったか。
  • 写真、招待リンク、他の人の名前やメールアドレスは送らないでください。
  • 安全に関わる連絡は、48時間以内に最初の返事をします。ほかは順番に返します。

この窓口は緊急通報先ではありません。生命・身体への差し迫った危険は、地域の緊急窓口へ連絡してください。

販売について

  • 販売するもの：ねこのまど Plus（月ごとに自動で更新されるサブスクリプション）
  • 価格：月額980円（税込）。初めての方は14日間無料で試せます。
  • 支払い：Appleを通じて、毎月の前払いです。お試しのあとは、お試しが終わった日に支払いが始まります。
  • 使える時期：購入したあと、すぐに使えます。
  • 解約：iPhoneの「設定」→ 自分の名前 →「サブスクリプション」→「ねこのまど」。次の更新日の24時間前までに解約すれば、次の料金はかかりません。
  • 返金：Appleが受け付けます。Appleの「問題を報告する」（reportaproblem.apple.com）から申し込んでください。運営者は返金を行えません。
  • 事業者：個人が運営しています。氏名・住所・電話番号は、請求をいただいたら遅滞なくお知らせします。
