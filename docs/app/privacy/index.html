プライバシーポリシー

最終更新日：2026年8月24日

このポリシーは、共有機能を完全に無効にした「ねこのまど」完全ローカル版に適用します。現在の共有ベータ版とは別の仕様です。

この完全ローカル版では、写真の読み込み、解析、猫判定、一覧、Widget用画像の処理は端末内だけで行います。共有・招待・送信・受信はなく、アプリから開発者のサーバーへ通信しません。公開フィード、検索、フォローもありません。

1. 開発者が収集するデータ

この完全ローカル版のアプリは、開発者によるデータ収集を行いません。アカウント、広告識別子、解析情報、利用履歴、位置情報を開発者のサーバーへ送りません。広告、トラッキング、データ販売、生成AIの学習にも利用しません。

2. 写真と猫判定

利用者が許可した写真へのアクセスは、写真の一覧表示、端末内の猫判定、アプリ内表示、Widget用画像の準備にだけ使います。写真、縮小画像、判定結果、Widget表示用画像などの派生画像を、開発者やその他の外部サーバーへ送信しません。

写真アクセスを許可しない、または選択した写真だけを許可することができます。許可範囲はiPhoneの「設定」から変更できます。

3. Widgetと端末内保存

Widget用画像と表示に必要な設定は、このiPhoneのアプリとWidgetが使う端末内領域で処理します。共有相手、招待、送信待ち、受信履歴、サーバー上の写真は作成しません。

アプリが写真や派生画像を写真アプリやiCloudへ独自に保存することはありません。CloudKitやアプリ独自のiCloudコンテナも使用しません。利用者が有効にしているiCloud写真やiPhoneバックアップはAppleと端末の設定によるもので、本アプリ独自の保存機能ではありません。

4. 通信

完全ローカル版のアプリには、写真共有、招待、送信、受信、公開フィード、検索、フォローのためのサーバー通信はありません。開発者の共有サーバーや解析サービスへ自動接続しません。

利用者がサポートページやApp Storeを自分で開いた場合は、ブラウザやAppleのサービスが通信します。TestFlightまたはApp Storeによる配布、クラッシュ情報、利用状況の扱いにはAppleの設定とポリシーが別に適用されます。

5. 削除

アプリを削除すると、アプリとWidgetが持つ端末内データはiOSの通常の削除対象になります。本アプリは開発者のサーバーへデータを保存しないため、開発者側へ削除を依頼する利用者データはありません。

6. お問い合わせ

技術的な問い合わせとプライバシーに関する連絡方法は完全ローカル版のサポートページに記載します。公開の問い合わせに写真や個人情報を添付しないでください。
