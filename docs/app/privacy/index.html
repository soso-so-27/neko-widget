プライバシーポリシー

最終更新日：2026年8月24日

このポリシーは、共有機能を完全に無効にした「ねこのまど」完全ローカル版に適用します。現在の共有ベータ版とは別の仕様です。

非公開で連絡できるプライバシー問い合わせ窓口は現在未掲載です。App Storeで一般提供する前に、このページへ有効な非公開窓口を掲載する必要があります。現在、この完全ローカル版の一般公開の提出準備は完了していません。

この完全ローカル版では、写真の読み込み、解析、猫判定、一覧、Widget用画像の処理は端末内だけで行います。ほかの利用者とのネットワーク写真共有・招待・自動送信・受信機能はなく、アプリから開発者のサーバーへ通信しません。公開フィード、検索、フォローもありません。

1. 開発者が収集するデータ

この完全ローカル版のアプリは、開発者によるデータ収集を行いません。アカウント、広告識別子、解析情報、利用履歴、位置情報を開発者のサーバーへ送りません。開発者の解析サービスへ自動接続せず、広告やトラッキングを行いません。データ販売、生成AIの学習にも利用しません。

2. 写真と猫判定

利用者が許可した写真へのアクセスは、写真の一覧表示、端末内の猫判定、アプリ内表示、Widget用画像の準備に使います。本アプリが写真やデータを自動で開発者のサーバーへアップロードすることはありません。

写真アクセスを許可しない、または選択した写真だけを許可することができます。許可範囲はiPhoneの「設定」から変更できます。

本アプリは写真アプリに「うちの子」アルバムを作成・更新し、選別した元写真のアルバム所属を追加・解除します。このアルバム連携では元写真を複製、書き出し、アップロードせず、写真ライブラリから削除もしません。

3. Widgetと端末内保存

Widget用画像と表示に必要な設定は、このiPhoneのアプリとWidgetが使う端末内領域で処理します。共有相手、招待、送信待ち、届いた写真の一覧、サーバー上の写真は作成しません。

写真アプリとiCloud写真の同期はAppleと利用者の設定によります。iCloud写真が有効な場合、「うちの子」アルバムの構成がほかのApple端末へ同期されることがあります。これは本アプリから開発者のサーバーへの送信ではありません。本アプリはCloudKitやアプリ独自のiCloudコンテナも使用しません。

4. 利用者が選ぶ書き出し

利用者がPDF、検証JSON、診断ログの書き出しを明示的に選ぶと、iOSの共有シートが開きます。共有先を選んだ後は、その共有先のサービスとポリシーが適用されます。

写真PDFには利用者が選んだ写真が含まれます。検証JSONや診断ログには写真・アプリ状態に関する識別子や診断情報が含まれる場合があります。内容と共有先を確認してから共有してください。

5. 通信

完全ローカル版のアプリには、写真共有、招待、送信、受信、公開フィード、検索、フォローのための自動サーバー通信はありません。開発者の共有サーバーや解析サービスへ自動接続しません。前節の書き出しは利用者の操作でiOSの共有シートを開くもので、送信の有無と共有先は利用者が選びます。

利用者がサポートページやApp Storeを自分で開いた場合は、ブラウザやAppleのサービスが通信します。TestFlightまたはApp Storeによる配布、クラッシュ情報、利用状況の扱いにはAppleの設定とポリシーが別に適用されます。

6. 削除

アプリを削除しても、「うちの子」アルバムやその構成が写真アプリに残ることがあります。アプリとWidgetの専用領域にあるデータはiOSにより削除されます。写真ライブラリの元写真は削除しません。不要なアルバムは写真アプリで削除できますが、アルバムを削除しても元写真自体は写真ライブラリに残ります。本アプリは開発者のサーバーへデータを保存しないため、開発者側へ削除を依頼する利用者データはありません。

7. お問い合わせ

GitHub Issuesへの案内は公開されるため、個人情報を含まない技術的な問い合わせだけに利用してください。写真、検証JSON、診断ログ、メールアドレスなどを投稿しないでください。プライバシーに関する非公開の連絡先としてGitHub Issuesを案内するものではありません。
