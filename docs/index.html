撮りためた猫の写真に、毎日会える

ねこのまどは、iPhoneの写真から猫の写真を見つけて、アルバムとホーム画面のウィジェットに出すアプリです。お気に入りの1枚は「まど」で、家族や猫友に届けられます。公開フィード、検索、フォロー、匿名の出会いはありません。広告もありません。

プライバシーポリシー

iPhoneの中だけで扱うもの、まど・家族の手帳・自動保存で扱う情報、保持と削除を説明します。

コミュニティ基準

まどで共有してはいけない内容、通報とブロック、対応の方針です。

サポート

よくある質問と、お問い合わせの窓口です。
