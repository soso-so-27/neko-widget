名前を付けたまどへ、一枚ずつ

この共有仕様は、本人所有の2台で確認中の内部TestFlightベータです。App Storeで一般提供している版ではありません。

「ねこのまど」は、名前を付けた1つの非公開なまどを、作成者と信頼できる招待相手1人がそれぞれ1台のiPhoneで使い、一枚ずつ写真を届けるアプリです。家族に限定しません。公開フィード、検索、フォロー、匿名の出会いはありません。広告もありません。

配布中のBuildによっては、共有鍵のペアリングだけが有効で、写真の保存・送信は無効です。アプリ内の表示が、そのBuildで実際に有効な範囲です。

プライバシーポリシー

写真、識別子、配送記録、通報時の例外、保持と削除を説明します。

コミュニティ基準

招待した相手との小さな共有でも守る内容、通報、ブロックの基準です。

サポート

ペアリングや送信の確認方法、問い合わせ時に共有しない情報を案内します。
