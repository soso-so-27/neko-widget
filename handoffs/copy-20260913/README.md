## 今回揃える説明

> 猫の一枚を、ホーム画面へ。iPhoneの猫写真を見返したり、「どこかの猫」「おひるね」から一枚を受け取ったり。親しい相手には、ひとことを添えて届けられます。現在は招待制の無料テスト中です。

説明上の区別は次の3つに揃える。

| 使い方 | 今できること | 誤解させないこと |
|---|---|---|
| 自分の写真を楽しむ | 猫写真の発見・自動アルバム・Widget・思い出、対象写真がそろった月の便り・季節ムービー | 猫登録や共有を必須にしない。猫個体の自動識別を提供中としない |
| 運営から受け取る | 「どこかの猫」「おひるね」を選んで、公開画像をアプリとWidgetで見る | 投稿・相手の招待は不要。非公開まどの写真が掲載される仕組みではない。AIの出自を表示する |
| 親しい相手へ届ける | 開いた写真から非公開まどを選び、任意のひとことを添えて送る。受信側はハートや明示保存ができる | 非公開共有だけの暗号化・ハート・保存を、公式まどにもある機能として説明しない |

Plusは販売準備中。利用者の公開投稿、会員の優先掲載、施設との連携、猫別の公開まどは現在機能の紹介に加えない。
