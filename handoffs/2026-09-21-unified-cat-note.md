# 写真に添えるメモの統一

## 利用者の操作

写真の鉛筆で自分だけのメモを書く。写真をまどへ追加するときは、写真だけでも送れる。自分のメモがある場合は「自分のメモを添える」を押したときだけ全文を送信用の入力欄へコピーし、相手・写真・送る本文を確認する。送信画面で新しく書くこともできる。

相手と共有した写真からは「共有メモ」を開く。同じ写真について、それぞれが自分のメモを追加・編集する。従来の共同記録一覧と内容は維持し、表示名を共有メモに揃える。

今回から写真を追加するときは、まどIDと配信写真IDから安定した記録IDを作る。同じ写真を開き直した場合や相手側から開いた場合は既存の写真へ戻る。取り下げ済みも新規追加扱いにしない。以前のランダムIDの記録は本文や見た目で推測統合せず、従来の一覧で保持する。

## 保存・共有の契約

| 場面 | 残るものと共有範囲 |
|---|---|
| 個人写真のメモ | 従来の写真ID・本文を維持。自分だけ。500文字まで |
| 送信画面の入力 | 送信する写真に添える本文。自分の元メモは書き換えない。100文字・改行2個の既存契約を維持。長文の無断切捨てなし |
| 送信失敗・宛先変更 | 同じ写真と入力を保持。送信時に確定した写真・宛先・本文を既存送信処理へ渡す |
| 送信取消 | 非空の入力は破棄確認を表示。「戻る」なら維持。明示して破棄した送信用入力は保存しない。元の個人メモは残る。アプリ強制終了をまたぐ新しい下書き保存は追加しない |
| 送った写真の本文 | 送信時点の文章。後から個人メモを編集しても相手の表示を変更しない |
| 共有メモ | このまどの二人で読む。本人の文章だけ編集・取り下げ可能。相手の送信本文を本人の文章として自動コピーしない |
| 写真から共有メモへ追加 | 本人が追加を確定した時点で鑑賞用コピーを既存の共同記録へ保存。閲覧だけで配信履歴を長期保管へ移さない |
| iCloud保管 | 既存の本人同意・保管コピー・本文反映の契約を維持。新しい文章の種類や自動保管を追加しない |

入力部品を共通化し、「自分だけ」または共有相手を入力の近くに示す。空欄には「このあと、どうなった？」を一つだけ表示する。回答は任意で、写真だけでも完了できる。ヒントの自動入力、通知、連続記録、カテゴリは追加しない。

## 確認範囲

元メモの保持と明示添付、送信先変更・再試行・取消、長文、共有写真への追加・本人編集・取り下げ・共有終了を既存の関連テストで確認する。新しい共有写真の識別に必要な境界確認を既存verifierへ足す。UI描画は同じテストの画像を利用し、別の全画面巡回は行わない。

実装・独立レビュー・自動検証・Appleアップロードは結果が得られた段階で記録する。実2台での同期と利用者にとってのわかりやすさ・継続価値は、自動検証済みと扱わない。
