# まどのUI/UX修正とTestFlight 152

2026-09-12（日本時間）。[実機画像のレビュー](2026-09-11-window-device-uiux-audit.md)で整理したUX-01〜13を実装し、本線へ反映した。

## 変更した体験

| 対象 | 変更 |
| --- | --- |
| UX-01・03・04：追加、役割、設定失敗 | 「＋追加」を常設。「相手と送り合う」「写真を受け取る」で役割を表示。警告と再開操作を対象のまどにまとめ、保存状態に応じて同じ設定から再開・やり直しへ進める |
| UX-02：マイファミリーの表紙 | Widget出力から独立し、同じまどの有効な受信写真・送信済み控えから直近の表紙を表示。未送信・別まど・削除済み・期限切れの写真を除外し、画像なしと読込不能を区別 |
| UX-05・07：公式写真と管理 | 最新の写真を大きく、最近の掲載写真を小さな一覧へ。説明と受け取り停止は右上の「管理」へ。停止と継続を選べる確認画面を表示 |
| UX-06：受け取り前の確認 | 受け取りを始める前にも公開写真を閲覧できる。閲覧だけでは購読・Widget・永続キャッシュを変更しない |
| UX-08・09・10：掲載・更新の状態 | 掲載日・提供元・該当するAI生成表記を写真付近へ。取得中・新着なし・失敗・休止・掲載終了を区別し、通常の写真一覧に恒常的な配信ステータスを増やさない |
| UX-11・12・13：読みやすさと写真操作 | 文字拡大時は一列・縦配置へ。写真の音声ラベルに掲載情報を付与。ナビの背景を整え、2048pxの既存写真拡大とWidgetから対象写真を開いて一度で戻る操作を維持 |

既存の非公開まどのハートを維持。お題窓・猫別窓・公開投稿・課金機能は追加していない。
