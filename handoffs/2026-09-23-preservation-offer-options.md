# 個人保管の提供条件：50GiB案と、解約・誤削除の境界

2026-09-23時点の**判断資料**。販売条件の確定、購入画面・LPへの反映、実サービスの配備・有効化ではない。基点 `4c81d5f`。既定OFFの個人保管に対して、月額980円・対象者の初回7日無料という現在の検証案で、何を約束できるかを整理する。

## 結論

1. 売る価値は「容量」単体ではなく、猫だけのアルバム・Widget・メモ・必要な写真の別保存を一続きにすること。みてねは無料・無制限の保存を案内し（無料版の動画は1本2分まで）、プレミアム解約後もアルバムの写真・動画が勝手に消えないと明記している。有限容量や解約を理由とする突然の消去を、差別化には使えない。
2. **有料枠50GiB、7日間体験枠1GiBを初期仮説**とする。これは暗号化した選択JPEGコピーと本文の合計であって、写真アプリの原本・動画・全自動バックアップではない。実写真のサイズ分布と採算が未測定なので、販売約束・環境変数へはまだ反映しない。体験枠を分けるには、現在の会員状態が `active/grace/expired/unknown` だけで体験中を識別できないため、請求authorityと原子的な容量判定を追加する必要がある。
3. 更新停止と保管物の削除を結び付けない。利用者の追加指定により、**会員資格の期限切れ後は新規保存を止め、12か月間の閲覧・一括書き出しと事前通知を設けた後に削除する**。資格を検証できない期間は削除時計を止める。実際の通知・最終削除・復旧コピー内削除が未実装の間は、この期限を販売文言にしない。アカウント削除は本人による別操作とする。
4. 個別写真の誤削除には**30日ごみ箱**を次の設計目標とする。現状は本文を即時消去し、写真を削除キューへ入れるため、7日清掃期間を「元に戻せる期間」と呼べない。ごみ箱は暗号本文と写真参照を残し容量にも算入する別状態/表が必要であり、現在の `remove` を文言変更だけで流用しない。本人の「完全に削除」とアカウント削除はごみ箱とは別の明示操作にする。独立した復旧コピーにも削除期限と実行確認が必要。期間や削除運用は実装・法務/プライバシー確認後に公開する。

## 実装の事実と、顧客に言える範囲

| 項目 | 現状 | 提供条件までに必要なもの |
|---|---|---|
| 写真の範囲 | 選んだ閲覧用JPEGコピー（1枚20MiB以下、長辺4096px以下）と本文。iCloud写真の原本や動画を移さない | 「猫写真すべてをバックアップ」と呼ばず、選択/元写真との関係を画面と規約へ明記 |
| 容量 | `OWNER_QUOTA_BYTES` は一律の技術上限。`GET /v1/usage` は暗号化済み容量と予約・空きを本人へ返せるがnative表示はまだない | 会員/体験の違いを安全に判定し、使用量・上限・保存失敗時の救済をアプリへ表示 |
| 件数 | `MAXIMUM_RECORDS` は削除済みIDも数える内部上限で、空き容量があっても新規作成を止め得る | tombstoneの再送防止を守りつつ、未公表の件数上限が50GiBの約束を先に塞がない設計にする |
| 更新停止・資格終了 | 自動更新停止後も有効期間・猶予期間中は新規保存可。資格終了後は新規保存を停止。現行コードは閲覧・編集・単件書き出し・削除ができ、期限による消去はまだない | 決定した12か月閲覧・全件持ち出し、事前通知、一次/復旧コピーの最終削除を実装。会員失効とアカウント削除を分離 |
| 誤削除 | 削除時に暗号本文/写真参照を即時破棄。写真実体の7日清掃は遅延書込対策 | 30日ごみ箱・取消・完全消去・容量会計・清掃を一つの状態遷移として設計/検証 |
| 災害/機種変更 | 合成Apple/KMS/D1/R2のテストはある。実Apple、管理鍵、専用DB/R2、2台での復元は未確認 | 独立した復旧コピー、鍵/DB/R2の復旧訓練、実2台。R2保管そのものをバックアップ完了と呼ばない |

個人保管と「まど」の共有写真は、鍵・所有者・保持期間が別。50GiB案をまどごとの共有枠と解釈しない。共有アルバムの長期保管は別判断とする。

## ¥980の採算を見るための粗い境界

[Cloudflare R2 Standard料金](https://developers.cloudflare.com/r2/pricing/)は2026-09-23確認時、$0.015/GB-month、書込等$4.50/100万回、読出等$0.36/100万回、R2からの直接egressは無料。1GiB=約1.074GBとして無料枠・請求単位の切上げ前の**保存部分だけ**を示す。

| 1人の常時保存量 | R2 Standardの比例額/月 | ¥150/ドルと仮置きした場合（実勢レートではない） |
|---:|---:|---:|
| 1GiB | 約$0.016 | 約¥2.4 |
| 10GiB | 約$0.161 | 約¥24 |
| 50GiB | 約$0.805 | 約¥121 |
| 100GiB | 約$1.611 | 約¥242 |

R2の無料10GB-month等は**サービスのアカウント全体**の枠で、利用者ごとには得られない。R2の実請求は日次ピーク平均、暗号化やごみ箱/復旧コピーの増分、請求単位の切上げで変わる。[Workers/D1料金](https://developers.cloudflare.com/workers/platform/pricing/)ではPaid基本料$5/月と含有枠・超過課金がある。[AWS KMS料金](https://aws.amazon.com/kms/pricing/)の顧客管理鍵は$1/鍵・月だが、共有鍵か本人別鍵か未決定であり、管理鍵authorityも未配備。専用復旧コピー、写真検証、監視、障害対応、人件費、サポートはこの表に含まない。

[Appleの日本向けApp Store規約](https://developer.apple.com/jp/support/app-distribution-in-japan)ではApple IAPの手数料は、Small Business対象または自動更新1年目以降なら10%+決済5%、その他は21%+決済5%。税込980円、[標準消費税10%](https://www.nta.go.jp/english/taxes/consumption_tax/01.htm)を先に控除する単純な概算は1回あたり約757円/約659円で、実入金ではない。対象資格、返金、税額端数、為替、実際のproceedsをApp Store Connectで確認する。**保存費だけを引いて黒字とは判定できない**。

期限切れ後の保持が最大の変数。仮に50GiB上限まで使った1万人が同時に期限切れとなれば、R2一次保存だけで約$8,053/月、12か月で約$96,636（¥150/ドルと仮置きして約1,450万円）。これは実利用の予測ではなく厳しい上限例で、独立バックアップ・ごみ箱・通知・鍵・サポート費用を含まない。無料体験で離脱した人の保持費用も発生するため、実測前に50GiBを販売約束しない。

## 販売前に確定する順序

1. 実写真を本人の同意を得た限定環境で測り、1枚/人のP50・P95、暗号化後容量、体験から有料化、解約済み総保存量を観測。猫写真や本文の中身は原価計測へ収集しない。50GiB/1GiBが適切かを確認する。
2. 契約/画面には「選択したJPEGコピー」「上限」「有効期間中は保存可、資格終了後は新規保存停止・既存閲覧/持ち出し」「個別削除/完全消去」「事業終了時の連絡・持ち出し」を同じ意味で表示する。独立復旧コピーからの消去期限も確定し、法務/プライバシー確認前に永久保管や元画像復元を約束しない。
3. 容量プランのatomic判定、件数上限問題、使用量表示、全件持ち出し、ごみ箱・最終消去を実装する。ごみ箱の移行では暗号本文/写真の参照、二重削除・復活競合、期限切れ清掃、容量の予約、鍵喪失を独立レビューと実DB/R2境界テストに含める。
4. 共有資源の流用なしで専用DB/R2/管理鍵/JPEG providerを非公開に構築し、復旧コピーから実2台で復元。元iPhoneを失っても同じ本人だけが記録を取り戻せることを確認する。実写真での低速・容量超過・失敗時の再試行も確認する。
5. その後にだけLP/購入画面/App Storeの表現を揃えて販売を判断する。現行のiCloud保管は勝手に移行/削除しない。TestFlight・一般公開・課金開始・実サービス有効化は本資料によって許可されない。
