# 写真と言葉を、読み返せる体験へ

2026-09-20。依頼は「課金対象として価値あるものにまで仕上げて。使う流れ、解決する課題、何が嬉しいのか」。課金・一般公開は開始しない。

## 商品の中心

「撮りためた猫写真を、この子との出来事として残し、あとで自然に思い出せる」。保存操作そのものを商品にしない。Widget・猫のテーマ・時期の整理を入口に、見ていた写真へ一言を添え、普段のアルバムから読み返す。一人で成立し、毎日の日記・猫登録・家族参加を条件にしない。

### 使い方の例

1. Widgetや猫のアルバムで、昔のお風呂の写真に出会う。
2. 開いている写真に「はじめてのおふろ。タオルにくるまって、やっとひと安心」と添える。写真の選び直しは不要。
3. 大切な記録は、その写真と言葉を確認して自分のiCloudへ保管する。通常のメモ保存とiCloud保管は現在は別操作。自動保管とは案内しない。
4. アルバムの「写真と言葉」を開けば、端末のメモも保管した記録も同じ場所にある。「おふろ」で探せばその写真と言葉を開ける。
5. 日常にはWidgetと既存のアルバムで再会する。猫との過去に会いに行くために、保存先の名前や撮影年月を覚えておく必要を減らす。

### 課題と嬉しさ

| 今の困りごと | 得たい結果 | 今回の扱い |
|---|---|---|
| 写真は大量にあるが、その日の出来事は忘れる | 自分だけが覚えている言葉が写真と一緒に戻る | 既存の写真詳細のメモを再利用 |
| 「はじめてのおふろ」を保管したのにメモ一覧には見えない | 保存した場所を覚えず同じ入口で読む | 端末メモと保管記録の読み取り表示を統合 |
| 日付を覚えていないと探せない | 覚えている言葉や明示的な猫名から探せる | 本文・既知の猫名・実日付の検索 |
| テキストの管理一覧に見えて嬉しくない | 猫の写真と言葉を一緒に眺める | 写真を拡大、時期で整理、文字拡大へ対応 |
| iPhoneを変えると写真の参照が途切れる | 明示的に保管した写真のコピーと言葉を取り戻す | 既存iCloud経路を利用。別の実機での復元は未確認 |

## 調査と判断

- [みてね Premium](https://family-album.com/premium) は過去の再上映、月・年の短いムービー、コメントからの検索などを有料機能として提供している。
- [Day One](https://dayoneapp.com/features/) はOn This Day、検索・タグ・お気に入りを再読の手段としている。
- [Appleのジャーナル](https://apps.apple.com/jp/app/id6447391597) も写真付きの記録・検索・iCloud同期を提供する。[写真のピープルとペット](https://support.apple.com/ja-jp/108795) には犬猫の分類やメモリーがある。したがって、検索・保管・ペット分類を単独の独自価値とは扱わない。

これらから「写真を置くだけでは弱く、探し直す手間を減らし、見返したくなることが重要」と判断する。ただし、他社の機能や価格の存在は、本アプリの購入意向・収益・継続の証拠ではない。「猫の写真へ言葉を足せる」だけでも差別化は弱い。既存の猫に絞った再発見と、写真から記録、再読までのつながりを商品として評価する。

## 実装する範囲

- アルバム上部の入口は「写真と言葉」。端末メモだけの件数は出さない。
- 一覧は写真と言葉、実際に分かる撮影日・記入日・保管日で整理し、本文・猫名から検索する。未登録の猫名や撮影日は推測しない。
- 既知の明示リンク、元メモのrevision、保管内容が一致するコピーだけ一項目へまとめる。似た言葉・日付による推測統合はしない。
- 元メモと保管コピーが別内容なら両方を表示し、保管した記録を区別する。読む場所の統合であり、保存先の移行や双方向同期ではない。
- 閲覧だけでアップロード・再送しない。iCloudの追加取得は明示操作。端末メモとiCloudの読込失敗は分離し、一方の失敗で他方を隠さない。
- アカウント変更・バックグラウンド移行では保管記録の表示を破棄。別アカウントの記録を表示しない。
- 共同記録は相手と共有する別の範囲。本人の個人記録を自動で混ぜない。
