# ADR-024：無料体験・ねこのまど Plus・物販の境界

作成：2026-08-31  
状態：製品判断を採用。課金UI・販売・機能制限は未実装。無効状態のStoreKit 2クライアント基盤のみ実装済み

関連：[製品構造](製品構造.md)、[情報設計](情報設計.md)、[ADR-015](ADR-015-共有の配送設計.md)、[ADR-019](ADR-019-しおりと長期保管.md)、[ADR-023](ADR-023-季節の小さな映画.md)、[ADR-025](ADR-025-StoreKitと課金IDの境界.md)

## 背景

ねこのまどは、単なるWidget、有料の写真保存容量、または家族向けメッセンジャーとして売らない。無料でも、猫写真を見つけ、Widgetで再会し、思い出に残し、信頼できる相手と1枚を届け合い、基本のまとめを見返すところまで成立させる。

課金は無料体験の画質や安全性を落として解除させるものではなく、猫との時間が毎月整理され、作品として増え、複数の相手や猫へ広がり、機種変更後も対応範囲を引き継げる継続サービスに置く。物理商品は、この蓄積を明示的に「かたちにする」別の都度購入とする。

## 決定1：利用者へ見せる商品は3つだけにする

| 商品 | 価格 | 役割 |
|---|---:|---|
| **無料** | **¥0** | 製品の中心体験を最後まで試せる入口 |
| **ねこのまど Plus** | **月額¥980／年額¥9,800** | 毎月育つ整理・作品・複数まど・引き継ぎ |
| **本・プリント** | **都度購入** | 思い出を物理的な品へする出口。最初の商品価格は原価検証後に確定 |

初回の有料releaseに、安い下位サブスク、買い切りPro、作品パック、Creator、Business、Boostを加えない。料金比較を複雑にせず、年額を推奨、月額を選択肢として表示する。招待された相手には参加・受信・ハートのための課金を求めない。

価格は価値仮説であり、売上の保証ではない。月額¥590が月額¥980へ売上で勝つには、同じ継続率なら約1.66倍の有料世帯が必要になる。一方、継続する理由がなければ¥980は成立しないため、課金率だけでなく2・3・6・12か月継続率を判定する。

## 決定2：無料体験を意図的に壊さない

無料版は次を含む。

- このiPhoneでの猫写真の検出・一覧・基本Widget
- ねこのプロフィール1匹
- 自分で作れるまど1つ
- 招待されたまどへの無料参加。ただし製品上の総まど数上限は別途守る
- 1まど2人、1人あたり本人確認済みiPhone最大4台
- 1参加者・1まどあたり1日5枚。Plusでも同じ
- 受信、到着状態、ハート、通知、通報、ブロック、共有解除
- 思い出に残す、取り込んで残す、基本JPEG、基本PDF
- 直近の基本的な月の便り、四半期の基本的な季節ムービー、基本の自動アルバム

写真の画質、暗号化、通知、安全機能、通報・ブロック、受信、ハートを課金軸にしない。送信枚数を増やして課金させず、1日5枚という静かな共有体験を全プランで守る。無料利用者にも、発見、再会、保存、1つのまど、基本作品までの閉じた価値循環を提供する。

参加したまどは「招待された相手は無料」の対象であり、自分で作れるまどの課金枠を消費させない。ただし初期製品の理解可能性と端末資源の境界として、作成・参加を合わせた総まど数は1台3件までを維持する。上限へ達した場合は、課金ではなく既存まどの整理を案内する。

## 決定3：Plusは量ではなく、毎月増える結果へ課金する

Plusの完成時に提供する価値は次のまとまりとする。

- 自分で作れるまどを最大3つまで増やす。各まどの招待相手は無料
- 複数のねこのプロフィールと、利用者が明示した猫別整理
- 過去の月の便りを見返す一覧
- 月ごとのムービーと一年のムービー
- 季節・月・一年の作品の1080p書き出し
- 素材の差し替え、並べ替え、追加BGM・テーマなど、結果を自分向けに整える操作
- 似た写真・連写をまとめる候補整理と、Plus用の自動アルバム
- 実装済みの範囲を正確に示した、作品と整理状態の引き継ぎ

「引き継ぎ」は販売開始条件であり、実装・実機検証前には課金説明へ載せない。写真原本、届いた写真、暗号鍵を無期限に保管するクラウドバックアップとは呼ばない。StoreKitが購入権を復元しても、写真やE2E鍵が自動で復元されるとは限らないため、復元対象、保持期間、容量、全端末喪失時の挙動を購入前に明示する。

Plusは「機能をたくさん解放する」ではなく、次の結果として説明する。

> 整理しなくても、ねこと大切な人との時間が毎月ひとつの作品になる。

## 決定4：3タブの目的を変えず、課金タブを作らない

```text
写真：見つける・見る・思い出に残す
まど：相手へ届ける・受け取る
思い出：残した写真と自動のまとめを見返し、かたちにする
```

Plusやショップを4つ目のタブにしない。Plus対象の価値は、本来の目的を果たそうとした文脈でだけ案内する。

- 2つ目のまどを自分で作る
- 2匹目のプロフィールを追加する
- 月・一年のムービー、過去作品、1080p、素材編集を使う
- Plus対象の引き継ぎを設定する

起動直後、写真許可前、招待参加、写真受信、ハート、思い出への保存、通報・ブロックでは課金画面を出さない。未実装の価値を「近日公開」の大きなカードとして主画面へ置かない。

課金画面を実装する場合、実写真を発見した後に個人化する。見せる価値は3つまでとし、料金、更新期間、自動更新、解約方法、利用規約、プライバシー、購入復元を一画面から確認できるようにする。

## 決定5：契約の単位は購入者、共有権利の単位はまど

Plusを契約した人は最大3つのまどを作成またはPlus対象として支援でき、その各まどへ相手1人を招待できる。招待された人は、そのまどの参加・受信・ハート・通知にPlusを必要としない。招待されたまどは、その人が自分で作れる無料まど数を消費しない。既存のまどは、active participantであるPlus購入者が支援できるようにし、最初に作成した端末だけへ課金権限を固定しない。

ただし現行アプリには、App Store購入権を複数端末・複数まどへ安全に結びつける課金IDがない。共有のparticipant IDはまどごとに異なるため、課金情報を`PairingCredential`へ混ぜない。StoreKit購入時に共有IDとは別の仮名`BillingAccountID`を`appAccountToken`として使い、少なくとも次をServerで検証できる設計を別ADRで確定する。

- App Store Server API／StoreKit 2で検証したsubscription entitlement
- entitlementを持つ購入者と、その人が作成・支援するまどの対応
- Plus対象のまどを利用する招待相手の`sponsored`権限
- 購入、復元、解約、返金、請求猶予、失効、オフライン時の扱い
- 別のApple Account、同じ人の追加iPhone、まど解除後の再利用、再インストール

端末内のbooleanだけでPlusを判定せず、Share Extensionだけで購入させない。権利検証が一時的に失敗しただけで、既存の写真、まど、作品を削除しない。

## 決定6：既存利用者から機能を取り上げない

現在の無料βは1台3まどを利用できる。課金導入時に、既存の接続済み・設定中まど、名前、写真、Widget、思い出、猫プロフィールを削除、非表示、読み取り専用化しない。

課金開始時点で接続済みのまどは、Server側の明示的な移行記録により維持する。Server IDをまだ持たない設定中のまども端末内で消さず、接続完了時に一度だけ移行できる経路を用意する。新たなまどの作成だけを新しい作成枠へ従わせる。ローカルのインストール日時や消え得るフラグだけを既存権の根拠にしない。既存プロフィールと既存作品の扱いも、同じ移行計画を実装・実機検証してから制限を有効にする。

## 決定7：物販は思い出の出口に置く

物販は独立したショップタブにしない。

```text
思い出
→ 写真
→ かたちにする
→ 商品を選ぶ
→ 写真を確認
→ 注文用の複製を作る
→ Webでプレビュー・配送先・決済
→ 注文後は「つくったもの」で確認
```

初回は商品を1つに絞り、印刷原価、梱包、送料、再印刷、決済手数料、問い合わせ工数を実注文で確認してから価格を確定する。無料利用者も同じ価格で購入でき、Plus割引を前提にしない。Plusは写真整理と作品作成を楽にすることで物販と相乗効果を作る。

本・プリントは物理商品なので、App内デジタル機能のsubscriptionとは会計を分ける。iOS共有シートでPDFを他アプリへ渡すこと、本アプリが注文を受けること、Webで決済することを同じ操作に見せない。

「つくったもの」は、利用者が実際に作成または注文し、再訪できる完成物が存在した後だけ表示する。未購入の販売カードの名前には使わない。

## 実装段階

### 段階0：無料β（現在）

- 現行機能を無料のまま検証する
- Plus、価格、購入ボタンを通常画面へ出さない
- 一般公開に必要なmoderation、監視、問い合わせ、privacy、APNs運用を完成させる

### 段階1：継続価値

- 過去の月の便り一覧（無料βへ実装済み。最新月の未読導線を含む。現在のローカル写真から再構成し、まだ復元対象ではない）
- 月・一年のムービー
- 似た写真・連写の整理
- 作品と整理状態の引き継ぎ契約

内部feature flagで完成度を確認し、販売前に実データで再訪価値を検証する。

### 段階2：課金基盤

- StoreKit 2の商品取得、購入、復元、権利監視のクライアント基盤（無効状態で実装済み。商品ID・販売UI・機能制限は未接続）
- BillingAccountIDの安全な発行・復旧と、Serverでの冪等な取引確認
- 解約・購読管理導線
- Server entitlementと作成者／まどの対応
- 返金、請求猶予、失効、オフライン、機種変更、全端末喪失の状態遷移
- 既存β利用者の移行
- App Storeの価格・説明・Privacy回答・サポート手順

### 段階3：小規模な実課金

- 年額¥9,800を推奨し、月額¥980も選べるようにする
- 有効化世帯からの課金率、2・3・6か月継続、作品の再訪、復元成功、問い合わせ率を観測する
- 値下げで未完成を補わない。価格変更は実課金結果で判断する

### 段階4：物販

- 1商品だけ手動運用で原価・品質・返品を検証する
- 注文が実際に発生してから製造連携を自動化する

## 販売開始の必須条件

- 毎月新しい結果が生まれるPlus機能が実機で成立している
- StoreKit購入・復元・解約・返金・請求猶予・失効を検証している
- 作成者と招待相手の権利が別端末で正しく分かれる
- 既存まど・写真・Widget・思い出を壊さない移行がある
- 復元できるもの／できないものを購入前に説明できる
- 監視、問い合わせ、緊急OFF、moderation、privacy運用が有料利用者へ対応できる

この条件を満たすまで、無料βへ価格だけを追加しない。

## 成功指標

売上だけでなく、価値が継続しているかを世帯単位で見る。

- 実写真発見後のPlus案内到達率と購入開始率
- 有効化世帯からの月額／年額転換率
- 2・3・6・12か月継続率
- 月の便り、月・季節・一年のムービーの生成・再訪・共有率
- 2つ目のまど作成率と、招待相手の継続率
- 復元成功率、問い合わせ率、返金率
- 「かたちにする」開始率、注文完了率、商品別の実粗利と再購入率
