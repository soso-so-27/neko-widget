# ADR-001：写真シャッフルはアルバム更新を追従しない

- 状態：承認済み
- 日付：2026-08-15
- 確認方法：iPhone実機による手動スパイク

> **2026-08-17追記：** 本ADRの15〜20件先読みはBuild 8までの履歴である。高解像度化後は累積描画負荷が実機不具合になったため、Build 9からmanifest最大20件／公開Timeline最大2件へ変更した。現行resource判断は[ADR-008](ADR-008-高解像度WidgetのTimeline負荷制限.md)を参照する。

## 観測結果

Apple標準「写真シャッフル」にアルバムを指定した後、そのアルバムへ写真を追加しても新しい写真は壁紙候補へ反映されなかった。設定時点の写真集合がスナップショットとして保持される挙動だった。

## 判断

設計全体は維持する。

- 「うちの子」アルバムの生成・更新は実装する。
- 継続表示の主要経路としてWidgetKitウィジェットをP0へ上げる。
- アプリの中核であるスキャン、猫検出、選別、好きの蓄積は、アルバムとウィジェットの両方から利用する。
- アルバム更新後の壁紙反映には、写真シャッフル側でアルバムを設定し直す必要があるとアプリ内で案内する。

## 影響

- 「アルバムを一度指定すれば、その後の追加写真も自動で壁紙へ出る」とは説明しない。
- 写真シャッフルの自動追従を受け入れ条件から外す。
- ウィジェットはSmall / Medium / Largeをv1で実装する。
- 1回のtimelineで15〜20件を先読みし、WidgetKitのreload budget内で表示を切り替える。
- 猫中心クロップはアプリ内表示だけに適用する。WidgetのBuild 5表示方針は[ADR-003](ADR-003-Widget表示品質のBuild5範囲.md)で別途定める。

## 再検討条件

将来のiOSで写真シャッフルのアルバム追従挙動が変わった場合、改めて実機確認して本判断を更新する。
