## 現状（Build 14）

| 画面 | 状態 |
|---|---|
| 何のアプリかの説明 | **なし** |
| 写真アクセスの許可 | `PhotoPermissionView` あり |
| スキャンの進捗 | `ScanStatusView` あり |
| **ウィジェットの置き方** | **なし ← 致命的** |
| 肉球の説明 | **なし** |

**ウィジェットの案内がないため、渡された人は製品の核を一度も体験できない。**
ウィジェットの追加はOS側の5ステップ操作で、やったことがない人が多い。
**そしてアプリから自動で追加するAPIは存在しない。案内するしかない。**

---

## 全体の方針

- **5画面。それ以上増やさない**
- **機能の一覧を見せない。** 「何が起きるか」だけ
- **「本が作れます」と言わない**（本は出口、入り口では言わない）
- **「家族と共有」を前面に出さない**（単身の人が離脱する）
- **スキップできる。** ただしウィジェットの案内には必ず戻れる導線を残す

## 1画面目：何のアプリか

```
　　　　　　［アイコン］

　　　猫の写真は、
　　　撮るだけ撮って
　　　見ていないことが多い。

　　　このアプリは、その中から
　　　猫だけを自動で選んで、
　　　毎日ちがう1枚を
　　　ホーム画面に出します。

　　　　　［はじめる］
```

**ポイント**
- **1行目で罪悪感を名指しする**（調査で9万人が共感した痛み）
- 「整理します」「容量が空きます」は言わない（後者は嘘）

---

## 2画面目：写真アクセスの許可

```
　　　このiPhoneの猫写真を探すために、
　　　写真を読ませてください。

　　　・解析はすべてこの端末の中で行います
　　　・開発者のサーバーへ写真を自動送信しません
　　　・写真を消したり変更したりしません

　　　　　［写真へのアクセスを許可］

　　　　　あとで（スキップ）
```

写真共有を有効にした限定Buildでは、上の3行だけを次に差し替える。

```text
　　　・解析はすべてこの端末の中で行います
　　　・写真共有は別に同意した後、選んだ縮小1枚だけを暗号化して送ります
　　　・原本の自動送信・削除・変更はしません
```

**ポイント**
- **不安を先に潰す。** 全ライブラリを読む許可を求めるので、ここで信頼を得る必要がある
- 「すべての写真へのアクセス」を推奨するが、**「選択した写真のみ」でも動く**ことを添える
- 既存の `NSPhotoLibraryUsageDescription` は合格しているので、文言はそれと揃える

## 3画面目：スキャン中 → 結果（第一印象）

### スキャン中

```
　　　このiPhoneの猫写真を探しています

　　　　　　［進捗］

　　　新しい写真から先に見ています。
　　　全部の集計は、
　　　次にひらいたときに続きます。
```

**ポイント**
- **全件で20〜60分かかるので、待たせない設計であることを伝える**
- 速報（新しい順500枚）が数秒で出ることが前提

### 結果

```
　　　このiPhoneで見つけた

　　　猫写真は

　　　　2,847枚

　　　ありました


　　　一番古い1枚は
　　　2021年4月3日
```

**ポイント**
- **自分でも知らない数字が出る。ここが第一印象**
- ゼロ手間で、その人だけの数字
- 0枚だった場合の分岐は既に実装済み（空状態の案内）

## 4画面目：ウィジェットの置き方 ★最重要

**ここが欠けていると、製品が成立しない。**

```
　　　ホーム画面に、
　　　猫写真のまどをひとつ。

　　　　［図解1〜4を横スワイプ］

　　　　　［わかった］

　　　あとで見る（設定からいつでも開けます）
```

### 図解（4枚。実機のスクリーンショットに矢印を重ねる）

| # | 内容 | 添える文 |
|---|---|---|
| 1 | ホーム画面の空白を長押ししている図 | **ホーム画面の何もないところを長押し** |
| 2 | 左上の「＋」を指している図 | **左上の「＋」をタップ** |
| 3 | 検索欄に「ねこのまど」を入力している図 | **「ねこのまど」を探す** |
| 4 | サイズ選択と「ウィジェットを追加」の図 | **好きな大きさを選んで追加** |

### 実装上の必須事項

- **設定画面から、いつでもこの案内を開き直せること**（一度スキップした人が戻れる）
- **ウィジェットが未設置のときは、ホーム画面に「ウィジェットを置く」の導線を出す**
  （置いていない人は製品を体験していないので、そこを埋めるのが最優先）
- 図解は静止画で十分。動画やGIFは不要

## 実装後に必ず確認すること

1. **一度スキップしても、設定から4画面目に戻れるか**
2. **ウィジェットが未設置のとき、ホーム画面に導線が出るか**
3. 図解が実機のiOSバージョンと一致しているか（手順が変わっていないか）
4. 0枚だった場合に、既存の空状態の案内へ正しく分岐するか

## 配布はオンボーディング実装後

**オンボーディングが入るまで、他人には配らない。**

理由：**ウィジェットの案内がない状態で渡すと、許可 → スキャン → 枚数を見る → 終わり**になり、
**製品の核（毎日ホーム画面に猫が出る）を一度も体験せずに削除される。**

外部TestFlightへ進む前に、対象BuildのBeta App Review、共有環境の安全gate、写真・暗号化の申告がすべて揃っていることをBuild単位で確認する。過去Buildの承認や公開リンクの存在だけでは、次のBuildを配布できる根拠にしない。
