# 個別写真からまどへ届ける（C3）

2026-09-09。写真を開いたまま、参加中のまどを選んで既存の送信前確認へ進む。

- 写真詳細の「思い出に残す」の下に、控えめな「まどへ届ける」を置く。
- 押した時に表示している写真を固定する。思い出保存・猫登録は条件にしない。
- 届け先は現行同意と接続が有効なまどだけ。0件では案内と「やめる」を出し、閲覧へ戻れる。
- まど選択後、同じ写真の高画質な表示用画像をPhotoKitから取得し、既存のcanonical JPEG変換を使う。サムネイル・原本ファイル・位置情報は送信元として保持しない。
- 確認は既存MomentDeliveryComposer。写真・届け先・任意のひとことを見て「届ける」で確定する。「変更」で届け先を選び直しても写真と本文は保つ。
- 選択・取消では写真をstageせず、activeまども変更しない。明示送信時に必要な場合だけ既存のまど切替APIを使い、元の宛先ID・認証binding・表示名を再照合して既存送信処理へ渡す。
- 読み込みの取消・遅い結果・二重tapを抑止する。送信開始に失敗した場合は写真と本文を残して再試行できる。
- ローカルの受付成功は「送信を開始しました」と案内して元の写真に戻る。「まど」の「送った」で既存の送信状況を確認できる。相手への到達完了とは表示しない。
- 既存の「思い出の写真を書き出す」は保存済み写真の条件を維持する。共有無効・ペアリング専用ビルドに入口を出さない。

確認対象は、表示中の2枚目・未保存写真、宛先変更と本文保持、取消時の送信ゼロ、まど0件、画像取得失敗、遅延取得の取消、送信失敗後の再試行、標準・最大文字。
実環境の写真取得・相手への到達・TestFlight配布状態は、CIの描画・操作確認と区別して配布記録へ残す。
