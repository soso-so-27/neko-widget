# 季節ムービー音源

`SeasonalMovieAmbient.dataset/seasonal-movie-ambient.wav` は、Yoiyami の
「First Light Particles」の冒頭24秒をアプリ用に変換した音源です。静かな
ピアノとパッドを中心に、写真や月表示の邪魔をしない季節ムービー用BGMとして
使用します。

## 収録仕様

- stereo PCM
- 48,000 Hz / 16 bit
- 24秒
- 変換コマンド:
  `ffmpeg -i first_light_particles_0.wav -t 24 -ar 48000 -ac 2 -c:a pcm_s16le seasonal-movie-ambient.wav`

## 再生契約

- 利用者が作品を開き、音をONにしているときは消音モード中も聞こえる
  `.playback` 再生
- アプリ内再生とMP4書き出しは、ともに最大音量55%
- 開始0.25秒でフェードイン
- 最終画面を0.8秒保ったあと、1.0秒でフェードアウト
- MP4はAAC 48,000 Hz / stereo / 128 kbps
