# 情報設計

最終更新：2026-08-21

この文書は、機能追加時に画面の置き場所と言葉を決める基準である。技術の構成ではなく、利用者の目的で分類する。

## 製品の中心

> 埋もれていた猫が毎日「まど」に戻り、残したい一枚へ肉球を押せる。

スキャン、分類、写真アプリのアルバム、共有サーバーは、この体験を支える手段であり最上位の目的ではない。

## 最上位の画面

下部タブは常に次の3つとする。

| タブ | 目的 |
|---|---|
| **まど** | いま表示している一枚を見る |
| **思い出** | 過去の猫写真を見返す |
| **これ好き** | 自分で残した写真を集め、PDFや本へ進める |

設定は「まど」右上の歯車から開く。共有が実装されても、まずは「まど」の中へ入れ、下部タブを条件付きで増減させない。

## 用語

| 用語 | 意味 |
|---|---|
| **まど** | 写真が巡回する空間。ひとりでも家族でも成立する |
| **家族のまど** | 招待した少人数が写真を届け合うまど |
| **ウィジェット** | 1つのまどをホーム画面から見る窓枠 |
| **いまの一枚** | 共有シートから明示的に届ける写真 |
| **思い出の一枚** | 過去写真から巡回する写真 |

「共有ボックス」は保存・バックアップを連想させるため使わない。1ウィジェットは1つのまどだけを表示し、異なるまどを混ぜない。

## まど

表示中の写真を最上位に置き、主要操作は肉球と写真詳細だけにする。

- 自分の過去写真：`思い出から・2022年`
- いま届いた写真：`いま届いた・○○さんから`
- 家族の過去写真：`思い出が届いた・2022年`

ウィジェット未設置時は、写真の近くに「ホーム画面にまどを置く」を出す。スキャンや権限に問題があるときだけ、短い修復導線を出す。正常時の処理件数、統計、写真アプリ連携、診断は常設しない。

家族共有を利用するときは、上部でまどを切り替える。まどが1つなら切り替えを表示しない。複数のウィジェットには、Widgetの編集画面で別々のまどを割り当てる。

## いまの一枚を届ける

送信開始地点は標準カメラまたは写真アプリの共有シートとし、アプリ内カメラや「送る」タブを作らない。

```
標準カメラ → 写真の共有 → ねこのまど → 送信確認 → 家族のまど
```

無料で家族のまどが1つなら届け先を選ばせない。複数のまどを持つ場合だけ選択する。アプリ内の「まど」には、初回の送り方案内、最後に届けた写真、最近届いた写真、失敗した送信の再試行を置く。

新着は2〜4時間または肉球の反応まで優先し、出所を明記する。優先期間後はまどの履歴へ移し、通常の思い出巡回へ戻す。

## 思い出

説明でき、見返す価値がある分類だけを出す。

- 猫ごとの成長
- 年ごと／年齢ごと
- 人といっしょ
- 猫たち
- どアップ
- すべての猫写真

姿勢を縦横比だけで断定するアルバムは出さない。猫プロフィールは全写真を自動判定したようなフィルターにせず、名前、日付、確認済み写真、成長、写真追加を持つ猫ごとのページとして扱う。成長は比較できる2時期以上がある場合に通常アルバムとして出す。

## これ好き

肉球を押した写真と、その出口を一つの画面へ集約する。

- `12 / 30枚`の進捗
- 写真グリッド
- 30枚に達したときのPDF書き出し
- 将来の物理的な本

総枚数を未読通知のような赤いタブバッジで表示しない。物理的な本を注文できない間は「PDFに書き出せます」と事実どおりに案内する。

家族から届いた写真は、既定では家族のまどの履歴に置く。肉球または明示的な「思い出に残す」を行った写真だけを個人のこれ好き／本へ入れる。

## 設定と診断

通常設定には写真アクセス、対象範囲、うちの子、写真の整理、ウィジェット案内、プライバシー、ヘルプだけを置く。誤って除外した写真を戻す操作は「写真の整理」に残す。

再スキャン、精度標本、2048px再試行、JSON、ログ、検出閾値は「詳細・診断」へ隔離する。bbox、FeaturePrint、deferred、manifestなどの内部語を通常画面へ出さない。

## 将来機能の置き場所

| 機能 | 置き場所 |
|---|---|
| まどの作成・招待 | まどの空状態／まど上部 |
| 最初の20枚の確認 | まど作成フロー |
| 過去写真の毎日1枚 | まどごとの設定。既定OFF |
| いまの一枚の送信 | Share Extension |
| 送受信履歴 | まどの履歴 |
| 通報・ブロック・退出 | 写真メニュー／メンバー管理 |
| E2E・保持期間 | セットアップの短い説明＋まど設定の詳細 |
| 2つ目以降のまど・課金 | 新しいまどを作る瞬間 |
| 成長・プロフィール | 思い出 |
| PDF・本 | これ好き |
| 開発検証 | 設定＞詳細・診断 |

## 成功の判定

主な成功はスキャン枚数やアプリDAUではなく、ウィジェット設置と実写真表示で測る。

- 写真許可から最初の候補までの時間
- 24時間以内のウィジェット設置率
- 最初の非placeholder表示までの時間
- 7日後にウィジェットが残る割合
- ウィジェットから写真を開き、肉球を押した異なる写真数
- 誤写真の除外数／100表示
- 30枚到達とPDF書き出し率
