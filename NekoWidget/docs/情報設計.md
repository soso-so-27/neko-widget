# 情報設計

最終更新：2026-08-26

この文書は、機能追加時に画面の置き場所と言葉を決める基準である。技術の構成ではなく、利用者の目的で分類する。

## 製品の中心

> 埋もれていた猫が毎日「今日」とウィジェットに戻り、残したい一枚を「思い出」に残せる。

スキャン、分類、写真アプリのアルバム、共有サーバーは、この体験を支える手段であり最上位の目的ではない。

## 最上位の画面

共有を利用できるreleaseでは、下部タブを次の3つとする。共有を提供しないreleaseでは「まど」だけを表示せず、「今日」と「思い出」の意味や位置を変えない。「写真を見つける」は「今日」から開き、独立した下部タブへ戻さない。

| タブ | 目的 |
|---|---|
| **今日** | このiPhoneから選ばれた一枚を見る。「写真を見つける」から過去の猫写真を分類して見返す |
| **まど** | 名前付きの非公開なまどを選び、写真を届け合う |
| **思い出** | 自分で残した写真を集め、必要な分だけまとめる |

設定は「今日」右上の歯車から開く。`まど`は共有全体の抽象名ではなく、利用者が名前を付けて相手を招待する各共有単位にも使う。下部の「まど」は、その一覧と選択の入口である。

## 用語

| 用語 | 意味 |
|---|---|
| **今日** | このiPhoneの一枚を見る最上位画面。保存先ではなく、「写真を見つける」への入口を持つ |
| **まど** | 利用者が名前を付け、信頼できる相手を招待して写真を届け合う非公開スペース |
| **ウィジェット** | 選んだ「このiPhoneの猫写真」または1つのまどを、iPhoneのホーム画面で見る表示 |
| **いまの一枚** | アプリ内の写真選択または共有シートから、送信前に確認して届ける1枚 |
| **思い出の一枚** | 過去写真から巡回する写真 |
| **このiPhoneの猫写真** | このiPhoneから読める写真を端末内で確認した、共有ではないWidget写真源 |
| **届いた写真** | 1つのまどへ届き、このiPhone内に期限付きで保持している写真の一覧 |
| **思い出に残す** | 自分のために残す操作。届いた写真では、位置情報を除いた写真を写真アプリへ取り込み、通常の思い出・PDF・将来の本の対象にする |
| **ハートを送る** | 届いた一枚に対する気持ちを、写真を届けた相手へ返す操作。保存はしない |
| **ねこのプロフィール** | 名前、日付、利用者が明示した写真を猫ごとに管理する場所 |
| **写真アプリの「うちの子」アルバム** | 既存互換のため維持するPhotos出力アルバムの固有名 |

「履歴」は送信記録や操作記録にも読めるため、受け取った写真の一覧名には使わない。「共有ボックス」は保存・バックアップを連想させるため使わない。`うちの子`は単独では対象が曖昧なため、既存Photosアルバムの固有名を明記するとき以外は使わない。1ウィジェットに異なる写真源や複数のまどを混ぜない。

## 今日

このiPhoneから選ばれた一枚を最上位に置き、「思い出に残す」と写真詳細を主要操作にする。共有写真と相手への「ハートを送る」は各まどに置き、「今日」の一枚へ混ぜない。アイコンだけで意味を説明せず、利用者向けには操作名を表示する。

- 撮影年が分かる写真：`このiPhone・2022年`
- 撮影年が分からない写真：`このiPhoneの写真`

ウィジェット未設置時は、写真の近くに「ホーム画面にウィジェットを置く」を出す。スキャンや権限に問題があるときだけ、短い修復導線を出す。正常時の処理件数、統計、写真アプリ連携、診断は常設しない。

「写真を見つける」は、このiPhoneで見つけた猫写真を成長・年・内容別に見返す入口である。「今日」自体を保存先や共有先として説明しない。

## まど

まどは名前、メンバー、最新の一枚、届いた写真、共有設定を持つ。家族関係を前提にせず、画面ではまど名、`相手`、`メンバー`を使う。

1つのまどは信頼できる2人だけに限定する。一方、同じiPhoneには複数のまどを作成・参加でき、画面上部で明示的に切り替える。写真、資格情報、送信待ち、届いた写真、Widget cache、Deep Linkはまどごとに分離し、不明なまどから別のまどへfallbackしない。1人は同じまどへ本人確認済みのiPhoneを最大4台まで追加できる。

通知を受け取れる設定と資格を持つ接続済みの各まどは、新着写真とハートのalertを受け取る。通知本文にはまど名・相手名・写真を出さない。通知が非選択中のまどに届いただけでは、そのまどをbackground同期せず、いま開いているまどやWidgetを変更しない。

通知をタップしたときは、通知対象と端末内で一意に一致するまどへ切り替え、そのまどを認証済み同期してから対象写真を開く。route用のopaqueなまど・写真IDは端末内の照合だけに使い、画面や通常の診断へ表示しない。解決できない通知から現在のまどや別の写真を推測して開かない。対象IDを持たない旧通知だけは、選択中のまどで「届いた写真」または「自分が届けた写真」の区分を開く。旧v2へ戻した場合は、選択中のまど1件だけへ通知する従来契約へ安全に縮退し、非選択中のまどを暗黙に同期しない。

## いまの一枚を届ける

主な送信開始地点は、名前付きのまど内にある「写真を選んで届ける」とする。Appleの写真選択画面で1枚を選び、写真・届け先・縮小と位置情報除去を確認してから送る。アプリ内カメラや独立した「送る」タブは作らない。標準カメラ／写真アプリの共有シートは、写真を見ている場所から送れる補助経路として残す。両経路とも同じサイズ上限、metadata除去、短期admission、Host appでの再検証と安全確認を通り、別の送信権限を作らない。

```
名前付きのまど → 写真を選んで届ける → Apple写真選択 → 送信確認
標準カメラ／写真アプリ → 共有 → ねこのまど → 送信確認
```

届けたいまどが1つなら、Share Extensionはその届け先を表示する。複数ある場合は、Host appが発行した期限内の候補だけをShare Extension内に並べ、利用者が1つを明示選択する。新規まどには重複しない既定名を付け、名前変更でも別のまどと同じ名前は保存しない。移行済みデータなどに同名が残る場合は番号だけで区別して送らせず、名前を変更するまでその候補を無効にする。未選択、削除済み、期限切れ、曖昧な旧形式では送信準備を止め、別のまどへ自動で切り替えない。Share Extensionは選んだ写真を端末内へ一時保存するだけで、Host appが選択ID、まど、同意、鍵、写真を再確認してから暗号化・送信する。非選択中のまどへ準備した場合は、完了画面でアプリの「まど」から対象名を開くよう案内する。アプリ内の「まど」には、初回の送り方案内、最後に届けた写真、最近届いた写真、失敗した送信の再試行を置く。

新着は2〜4時間または明示した表示条件まで「今日」とウィジェットで優先し、出所を明記する。優先期間後も、そのまどの「届いた写真」から見返せる。通常の思い出巡回とは混ぜない。

## アルバム

説明でき、見返す価値がある分類だけを出す。

- この家の猫たちの成長
- 明示した写真だけで作る猫ごとの成長
- 年ごと／年齢ごと
- 人といっしょ
- 猫たち
- どアップ
- すべての猫写真

姿勢を縦横比だけで断定するアルバムは出さない。「この家の猫たちの成長」は猫を見分けず、検出した猫写真から撮影年ごとに1枚を選ぶ。猫プロフィールは全写真を自動判定したようなフィルターにせず、名前、日付、この子だと明示した写真、成長、写真追加を持つ猫ごとのページとして扱う。世帯全体・個体別のどちらも、比較できる2時期以上がある場合だけ成長アルバムとして出す。

「この子の写真」は、アプリ内で手動確認した写真と、その猫へ利用者が明示的につないだ通常の写真アルバムの和集合とする。AIが個体を推測した写真は入れない。同じ写真を複数の猫へ入れられるため、2匹いっしょの写真を片方だけへ強制しない。

5枚の正解例を使った個体識別実験も、実機の評価30枚で必要な判定率に届かなかったため製品化しない。個体ページや個体別成長へ自動所属を追加せず、世帯全体の成長は個体識別なしで成立させる。

通常の写真アルバム連携は、ねこのプロフィール内の「写真を追加」から行う。アプリは連携元を読むだけで、写真アプリのアルバムや写真を移動・削除しない。連携を外してもアプリ内で手動確認した写真は残す。これは設定の全体共通の「写真の対象」や、アプリが作る写真アプリの「うちの子」アルバムとは別であり、互いの選択肢や内容を混ぜない。

## 思い出

「思い出に残す」で選んだ写真を上限なく残す場所とする。PDFは保存形式の一つであり、画面の主目的にはしない。

- 思い出に残した日時の新しい順に並ぶ、一続きの写真グリッド
- 現在「思い出」に残っている一枚の詳細メニューから選ぶ「写真を書き出す」
- 1〜30枚を明示的に選ぶ「まとめる」操作
- 選んだ写真だけのPDF共有
- 将来の物理的な本やプリント

「写真を書き出す」は現在「思い出」に残っている一枚だけを対象とする。長辺2,048px以下のJPEGを端末内で準備し、位置情報、撮影日時、元のファイル名などの元情報を除いてiOS共有シートへ画像データとして渡す。アプリ自身が管理する書き出し用の一時ファイルは作らず、元写真と「思い出」の状態も変更しない。iOSまたは利用者が選んだ共有先がコピーを作成・保持する場合があり、その共有先のポリシーが適用される。これは非公開なまどへの送信や物理プリントの注文ではない。

31枚目以降も消さず、最初の30枚だけを固定的に扱わない。総枚数を未読通知のような赤いタブバッジで表示しない。物理的な本を注文できない間は「一枚を書き出す」と「選んだ写真をPDFとして共有する」だけを事実どおりに案内する。

招待相手から届いた写真は、まずその非公開なまどの「届いた写真」に置く。操作しなければ最長90日・500枚・256MiBまでの一時的な受信履歴である。「思い出に残す」を選んだときだけ、位置情報を除いた写真を写真アプリへ一度取り込み、通常の思い出・PDF・将来の本と同じ個人コレクションへ加える。iCloud写真の同期は利用者とAppleの設定に従う。

「思い出から外す」は個人コレクションから外す操作であり、写真アプリの写真を削除しない。共有解除、ブロック、アプリ削除でも、明示的に取り込んだ写真は写真アプリに残る。相手へは通知しない。相手への反応は別の「ハートを送る」だけにし、ハートから保存を発生させない。

## 設定と診断

通常設定には写真アクセス、対象範囲、ねこのプロフィール、写真の整理、ウィジェット案内、プライバシー、ヘルプだけを置く。誤って表示候補から外した写真を戻す操作は「写真の整理」に残す。

再スキャン、精度標本、2048px再試行、JSON、ログ、検出閾値は「詳細・診断」へ隔離する。bbox、FeaturePrint、deferred、manifestなどの内部語を通常画面へ出さない。

## 機能の置き場所と現行状態

| 機能 | 置き場所 | 状態 |
|---|---|---|
| まどの作成・招待 | まどの空状態／まど上部 | 実装済み |
| いまの一枚を届ける | まど内のApple写真選択を主経路、Share Extensionを補助経路とし、どちらも送信前確認・Host app再検証・安全確認を行う | 実装済み。複数候補では未選択のまま進めず、自動fallbackしない |
| 届いた写真 | まど内の「届いた写真」 | 実装済み |
| 自分が届けた写真 | まど内の別セクション | 実装済み。サーバー受付済み／相手端末へ到着を分ける |
| 思い出に残す | 自分の写真、届いた写真、Widget | 実装済み。届いた写真はHost appで写真アクセスと取込を確認する |
| ハートを送る | 届いた写真とWidget | 実装済み。送信待ち／サーバー受付済みを分け、保存はしない |
| 新着・ハート通知 | まど設定 | クライアントとServerのAPNs経路を実装済み。通知を受け取れる接続済みの各まどへ一般文のalertを登録し、別envelopeのopaqueなまど・写真IDを端末内routingだけに使う。非選択中のまどへの通知だけでは同期・まど切替・Widget更新を行わず、タップ時に対象まどへ切り替えて認証済み同期後に対象写真を開く。解決不能時は別のまどへfallbackしない。IDのない旧通知は選択中のまどの「届いた」または「届けた」を開き、旧v2 rollback時は選択中の1まどだけへ安全に縮退する。APNsは同期のきっかけであり、端末到着やWidgetの即時更新を保証しない。非選択中のまどのbackground同期は後続課題。資格情報、runtime設定、実送信smokeはreleaseごとの運用gate |
| 通報・ブロック・共有解除 | 写真メニュー／メンバー管理 | 実装済み。一般公開にはmoderation運用が別途必要 |
| E2E・保持期間 | セットアップの短い説明＋まど設定の詳細 | 実装済み |
| まどの追加・切り替え | まど上部 | 実装済み。1まど2人、1人最大4台 |
| 成長・プロフィール | 今日＞写真を見つける | 実装済み。先頭の「すべての猫写真」から全件を見返せる。自動個体識別は提供しない |
| 単写真JPEG | 思い出の一枚の詳細メニュー | 実装済み。現在思い出に残っている一枚を長辺2,048px以下へ変換し、位置情報等の元情報を除いてiOS共有シートへ渡す。元写真と思い出状態は変更しない |
| PDF | 思い出 | 実装済み |
| 本・プリント注文 | 思い出 | 未実装。iOS共有シートの共有先と本アプリ内の注文を混同せず、利用可能になるまで購入できるように案内しない |
| 3人以上・一方向チャンネル | — | 未実装。現行の「まど」と混ぜない |
| 開発検証 | 設定＞詳細・診断 | 実装済み |

## 成功の判定

主な成功はスキャン枚数やアプリDAUではなく、ウィジェット設置と実写真表示で測る。

- 写真許可から最初の候補までの時間
- 24時間以内のウィジェット設置率
- 最初の非placeholder表示までの時間
- 7日後にウィジェットが残る割合
- ウィジェットから写真を開き、思い出に残した異なる写真数
- 誤写真の除外数／100表示
- 「まとめる」の利用率とPDF共有完了率
- 一枚の「写真を書き出す」の開始率と共有シート表示完了率
