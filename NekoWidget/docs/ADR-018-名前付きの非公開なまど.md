# ADR-018：共有先は家族限定ではなく、名前付きの非公開な「まど」にする

日付: 2026-08-23
状態: 提案・実装前
関連: [ADR-009](ADR-009-ローカルアルバムと招待制共有.md)、[ADR-017](ADR-017-家族共有v1とmoderation境界.md)、[情報設計](情報設計.md)

## 提案

製品上の共有単位を「家族」という関係ではなく、利用者が名前を付ける招待制の非公開な「まど」とする。友人、恋人、離れて暮らす人も利用できる一方、初期版の能力は次に限定する。

- 1人につき1つのまど
- 作成者と、信頼できる招待相手1人の合計2人
- 招待制、非公開、検索・公開feed・followなし
- まど名は変更可能な表示情報であり、spaceの識別子や暗号鍵に使わない

安全性は「家族」という呼称ではなく、人数、明示招待、二者確認、端末資格、E2E暗号化、通報、block、共有解除で守る。

## 用語

| 表示 | 意味 |
|---|---|
| `うちの子` | 猫プロフィール、猫の選別、Photosへ作るアルバム |
| `このiPhoneの写真` | 端末内で見つけた猫写真を使うWidget写真源 |
| `しずくのまど`など | 利用者が名前を付け、招待相手と一枚を届け合う共有空間 |
| `ウィジェット` | 選択した写真源またはまどを覗く表示枠 |

「箱」は保存・バックアップを連想させるため、共有先の製品語には使わない。現在Widget写真源に表示される「うちの子」は猫自体やアルバムと混同するため、「このiPhoneの写真」へ変更する。

## 段階

1. 表示語だけを整理し、「家族から」を「〈まど名〉から」、「うちの子（写真源）」を「このiPhoneの写真」へ変える。
2. 既存の単一spaceへ変更可能なまど名を追加する。既存利用者はペアリングを解除せず、初期表示名から任意に改名できる。
3. まど名を参加端末間で同期する。serverの識別子にはせず、可能ならroom keyで暗号化した設定payloadとして扱う。
4. 資格情報、履歴、Widget cache、deep link、Share Extension届け先をspace ID単位へ分離してから、複数のまどを追加する。
5. 鍵更新、招待承認、解除、deliveryを再設計してから、3人以上または1人の複数端末を追加する。

## 互換性

既存の内部識別子`personal-library`、`family-window`とdeep link `nekowidget://family-window`は互換入口として残す。表示名をidentifierへ使うと改名だけでWidgetや履歴が切れるため、既存spaceに安定したローカルIDを対応付ける。

この提案を採用するまでは、表示語や保存形式を一括置換しない。最初の実装候補は用語整理と単一まどの改名だけであり、複数まどや3人以上へ同時に広げない。
