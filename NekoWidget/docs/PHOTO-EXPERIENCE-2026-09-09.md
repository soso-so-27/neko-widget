# 写真を楽しみ、任意のひとことと一緒に届ける体験

## 目的と判定

写真が主役。ひとことは写真の気持ちを補う任意の要素。利用者が写真を選び、必要なら一言添え、送り先を確かめ、送った写真を見返し、相手もアプリ・Widgetで同じ写真を楽しめることを目標とする。

機能の存在、文字のはみ出しがないこと、CI成功だけで体験全体を完了としない。実装・描画・操作・実機での送受信を分け、以下の各場面を最後まで評価する。写真・自動アルバム・個人Widget・思い出・任意の複数猫管理を基準にし、共有や本文を必須にしない。

## 多角的な再評価

| 場面・観点 | 確認した問題／不足 | 設計・完了条件 |
| --- | --- | --- |
| 写真を見つけて選ぶ | 個別写真から直接まどへ進む入口は未実装。既存のまど内選択では一枚確認へ進める | 写真閲覧を共有参加で妨げない。個別写真入口C3は欠落として維持し、今回の既存表示の修正完了で消さない |
| 任意の入力 | 太い文字と濃い黒い面が写真以上に目立つ。本文なしでも入力入口が常に強い | 入力中だけ編集に必要な強調。確認中は写真中心、本文は通常の太さで短いプレビュー。入力終了・送信取消・送信確定を区別 |
| 宛先と確定 | 送り先はフッターに表示。送信前に全体取消できる | 写真・宛先・任意の本文を確認して一度確定。キーボード中も終了・取消へ戻れる。送信中の多重確定を防ぐ |
| 送信直後／一覧 | 写真ごとの受付・到着・日時・注釈が閲覧を配送管理画面にする。写真に太い本文を重ねている | 通常の配送状態を一覧から外し、知りたい時だけ写真詳細で確認。未送信・失敗等の対処が必要な状況は隠さない。写真と小さな補足を中心にする |
| 送信詳細の画質 | 240px（fallback160px）の一覧用JPEGを240ptへ拡大。高精細画面では粗くなる。送信済み元データは削除され復元不能 | 新規分は同じ送信用JPEGを保護された詳細用ファイルへ保存。一覧と詳細を分け、期間・件数・容量・削除を管理。旧低解像度分を高画質化したと偽らない |
| 受信一覧 | サムネイルにも文字・日付・保存／ハートを重ね、小さい写真を覆う | 写真の識別を優先。本文は控えめな一行の補足。操作と写真閲覧のタップ領域を明確にする |
| 写真を開く | 固定4:3枠で縦写真が小さく、本文を写真上と下で重複表示。説明が鑑賞領域を押し下げる | 画面に合った縦横比で全体を見られ、写真を遮らず拡大できる。本文は一度、必要な時に全文。閉じる位置を固定し元の一覧へ戻れる |
| 読込・画面回転 | 受信表示キャッシュはURLだけで一覧・詳細の要求画素数を区別しない | 詳細は保管JPEGから最大2048pxで読込。要求解像度をキャッシュに含め、前の小画像で詳細を固定しない。異なる写真の画素を残さない |
| 反応・残す | 写真と操作の関係より配送説明が強い。Widgetのハートは操作後の対象表示が未確認 | 同じ写真の近くに保存・ハート。送信待ち／受付済みを既読と呼ばない。保存先・解除・取消の既存意味を保つ |
| Widgetの視線と配置 | 小の52pt帯が写真を削り、まど名「み…」。大の太い3行本文が主役化。本文有無で操作上下が変わる | 同じ写真面積、同じ操作位置。小は短い一行、中大も補足として二行。通常の太さ・浅い背景。44pt領域を保ち、見た目の丸ボタンだけを控えめにする |
| 写真切替・失効 | 正しい写真URLのコードはあるが、失効時に説明なくまどへ戻る。Galleryは操作検証ではない | 古いWidgetでも同じ写真を開き、表示不能なら説明。別写真で黙って代用しない。文字なしへ切替時に前の本文を残さない |
| 読みやすさ・操作性 | 小の長文・大文字、VoiceOverの連続操作が未確認。実際の毛並みの見え方も図形fixtureで評価していた | 写真的な猫fixture（生成画像で、利用者の実写真ではない）、明暗・縦横、本文なし／短文／長文、大きな文字、読み上げ操作の実装、隣の操作・戻るを場面別に確認。図形による境界検査だけで画質を合格にしない |
| 遅延・失敗から戻る | 古い同期エラー残存はBuild141で修正。失敗説明が一覧全体を占有しやすい | 対応が必要な失敗は短く目立たせ、理由と再試行／取消は詳細へ。写真と本文を選び直させず、通常閲覧に戻れる |

## 今回まとめる修正

1. 写真の一覧・送信前・受信詳細の視線と情報の強さを揃える。
2. 新規送信詳細の画質と、受信詳細の表示・解像度キャッシュを直す。
3. Widgetの写真面積・補足本文・固定操作位置と、写真を開く連続性を直す。
4. 実際の描画と操作で見直し、発見した差分を同じ候補で閉じる。個別の指摘を直した時点で監査完了としない。

一覧用画像と詳細用画像の保持、写真／本文の同一性、解除・期限・消去は独立レビュー対象。検証を無制限に増やす目的ではなく、上の利用場面を満たした証拠を揃える。実行できていない項目を「問題なし」にしない。
