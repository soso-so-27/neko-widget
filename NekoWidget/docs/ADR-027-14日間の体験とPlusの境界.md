# ADR-027：14日間の体験と、ねこのまど Plus の境界

作成：2026-10-20
状態：所有者承認済み。2026-10-20昼の追加決定（まどは作った人がPlusで続ける）を反映。実装は PR 2（#416）・PR 3（#420）から着手（実装計画は [980円の階段_実装計画](980円の階段_実装計画.md)）
関連：[ADR-024](ADR-024-無料体験とPlusと物販.md)、[ADR-025](ADR-025-StoreKitと課金IDの境界.md)、[ADR-026](ADR-026-うちの子との時間と会員体験.md)、[課金と商品化の導線](課金と商品化の導線.md)

このADRは、2026-10-20に所有者が決めた料金の形を1本にまとめ、ADR-024・025・026のうち覆す点を明記する。設計の考え方（払う段差をなめらかにする5つの原則、Plusの1画面、欲しくなった5か所）は `claude-main/ねこのまど_980円への階段_1020.md` が正本で、本ADRはその決定部分だけを記録する。

## 背景

ADR-026で「ウィジェットと自動整理は、全部を試せる期間のあと有料にする」向きを採用したが、日数・価格・無料で残る範囲・体験のしくみは仮説のままだった。所有者はこの向き（案A）を承認し、「980円を払う階段をなめらかに、払いやすくしたい」と求めた。入口の価値（猫の写真が見つかる・ウィジェットに出る）を体験してから払ってもらい、続ける理由（まど）は家族を招くときに壁にならないようにする。

## 決定

### 1. 無料の範囲ですぐ使える。Plusは App Store のお試しオファーで14日間無料

- 入れたらすぐ、申込みなしで無料の範囲（2章の左列）を使える。
- Plus（月額980円）には、App Store Connect で **14日間無料のお試しオファー（Introductory Offer）** を設定する（設定は所有者）。お試しは Apple ID 単位で1回。期間後は月額980円で自動更新され、いつでも解約でき、やめても写真・まど・メモは消えない。
- **アプリ側で日数を数える「端末ごとに14日」の無料開放は行わない**（2026-10-20午後の所有者決定で撤回。PR #420 の `TrialPeriodStore` は外す）。申し込まない人は最初から無料の範囲だけで、ホーム画面のウィジェットは最初の1枚のまま（PR #429 の「最後の1枚を保つ」をそのまま使う）。
- 入口は「初回案内（スキップ可）」と「Plusの5か所」（5章）。どこから入っても同じ1つの購読。StoreKit の `isEligibleForIntroOffer` でお試しの資格を確認し、資格があれば「14日間無料で始める」、なければ「Plusを始める（月額980円）」を出す。
- 14日の根拠：RevenueCatの17,000アプリの調査（2025年8月〜2026年7月）で、月額プランの有料転換率は5〜9日の体験で45.9%、10〜16日で46.6%とほぼ同じだが、**1回目の更新が続く率は62.8%→72.0%**と差が大きい。毎日1枚のウィジェットは2週間見て習慣になる。
- お試しオファーに一本化する根拠：Apple のガイドライン3.1.1／3.1.2 が定める定期購読の無料体験の形であり、審査・復元・全端末での利用・ファミリー共有が Apple の仕組みに乗る。アプリ側の日数管理（Keychain・時刻の改ざん対策・再インストール）を持たずに済む。
- 伝え方：購入画面に価格・期間・自動更新・解約方法・利用規約・プライバシー・購入の復元を1画面で。初回案内の最後の1枚はスキップできる。カウントダウン・通知・全画面の催促は出さない。

### 2. 15日目からも消えない。育つものだけが Plus

| ずっと無料 | Plus（月額980円） |
|---|---|
| 見つけた猫写真の一覧、お気に入り、書いたメモを読む・編集する・書き出す | 自分の猫のウィジェットの**新しい1枚**（無料では最後の1枚のまま。空にしない・灰色にしない・ロックや一時停止のマークも出さない） |
| アルバム一覧（猫別・年別・月別の一覧）を見る | **月のまとめ・季節のムービーを開く** |
| 招待されたまどに入る、届ける、受け取る、ハート、届いた写真のウィジェット | **新しいメモを書く** |
| 公式のまど | **まどを作る・作ったまどを続ける**（5つまで。お試し中も作れる） |
| ツール5つ（写真を見せる・預けるとき・病院で見せる・迷子のとき・避難に備える） | |

- **ツール5つは無料**。払う理由を「毎日育つもの」に絞って言葉を1本にする。病院に行く日に「病院で見せる」で初めて壁に当たるのは、いちばん悪い場面。ADR-024の「基本機能・安全を課金軸にしない」と合う。
- **まどは作った人がPlusで続ける。入る人はずっと無料。** まどを作るのは1つ目からPlusの機能（お試し中を含む。「自分のまどを1つ、ずっと無料で作れる」は2026-10-20昼に撤回）。Plusで5つまで。
- 作った人の購読（お試しを含む）が有効でなければ、そのまどには**誰からも新しい写真が届かなくなる**。まど・写真・メンバー・ハートは残り、消えるものはない。Plusに戻れば再開する。ファミリー共有で家族の誰かがPlusなら続く（1世帯1契約）。
- **まどの合計上限は10**（自分で作ったまど＋招待で入ったまど。無料でもPlusでも同じ）。招待で入るのは無料で、プランで変えない。超えたら、課金ではなく整理を案内する。
- Plusをやめても何も消えない。新しく増えるものだけが止まる。

### 3. 価格は月額980円だけ

- 年額は最初は出さない。RevenueCatは「製品が固まる前・ブランドの信頼がまだない・継続のデータがない」段階では月額を主にすることを勧めている。価格が1つだと、Plusの画面も1つの数字だけになり段差が低い。
- 継続のデータが出てから年額（9,800円、2か月分おトク）を足す。上位プラン（1,480円など）は今は作らない。将来作るなら「容量を広げる」だけで、まどの数・端末数・ファミリー共有は差別化に使わない。
- **保存と復元は980円に含める**。1人あたりの枠（例：5GB・1,000件）で原価を閉じる。枠の数字は保存機能を公開するときに決める。お試し中も保存は使えるが、量に上限を置く（値は未定）。
- 商品 `jp.nekowidget.plus.monthly` に **14日間無料のお試しオファー**を設定する（1章）。
- 商品ID：`jp.nekowidget.plus.monthly`（既存のSandbox用スクリプト `ci/preservation-pilot-release.py` と同じ。App Store Connectに同じIDの商品があればそれを使い、なければこの名前で作る）。

### 4. Appleのファミリー共有を有効にする（2026-10-30 に取り消し：1.0 ではオフ）

> **2026-10-30 所有者決定で取り消し。** 1.0 では Plus のファミリー共有をオンにしない（買った本人だけが Plus）。理由：
> - 家族で使う中心のみんなのまど・家族の手帳は、招待された人が無料で使える。ファミリー共有で増えるのは、家族それぞれの個人の分（自分のウィジェットの毎日の 1 枚・作品・保存 3GB）だけになる。
> - 保存は 1 人 3GB の枠なので、980 円で最大 6 人分を預かることになり、採算が合わない。
> - 一度オンにすると戻せない。オフで始めて、あとでオンにすることはできる。
>
> 家族向けが必要になったら、別の商品（例：上位プラン）として作り、その商品だけファミリー共有をオンにする道を考える。権利の判定は PURCHASED だけを有効にしたままにする（Codex 1030d）。下の元の記録は、経緯として残す。

- 1人が払えば、同じファミリー共有の家族（本人＋5人）がPlusを使える。1つのまどの上限6人と数が合い、ADR-026「一つの家族の記録を一人の契約で支える」と合う。
- 一度オンにすると戻せない。**オンにする時期は、クライアント・検証サービス・Workerで `FAMILY_SHARED` の取引を受け入れる実装を終え、Sandboxで家族側の端末がPlusになることを確認したあと**。LPの「払うのは1人、使うのは家族」も、その時期に合わせて出す。

### 5. Plusの画面は「欲しくなった場所」にだけ出す

1画面だけ。見出しは「うちの子との毎日を、続ける」、価値は3つ、月額980円、こわさを消す3行（いつでもやめられる／やめても写真・まど・メモは消えない／招待した家族はずっと無料）、下に購入を復元・解約のしかた・規約。ボタンの文言は「何が起きるか」。

| 場所 | ボタン |
|---|---|
| 止まったウィジェットからアプリを開いた | ウィジェットの写真を、毎日新しくする |
| 月のまとめ・季節のムービーを開こうとした | 10月のまとめを見る（月名を入れる） |
| メモを書こうとした | メモを書く |
| 初回案内の最後（スキップ可） | 14日間無料で始める |
| まどを作ろうとした | まどを作る |
| 作った人が、止まったまどを開いた | このまどを続ける |
| 保存を使おうとした | 保存を始める |
| 設定 | Plusについて |

一文の説明：「まどは作った人がPlusで続けます。入る人はずっと無料。」 お試しの資格がある人には主ボタンを「14日間無料で始める」、ない人には「Plusを始める（月額980円）」にする。

出さない場面：写真の許可、招待参加、受信、ハート、お気に入り。初回案内の最後の1枚は例外として出すが、スキップできる。購入後は完了画面を出さず、元の画面に戻ってその場で続きが動く。やめるときの引き止め画面、割引の提示はしない。

## 覆す点

| 元の決定 | 本ADRでの扱い |
|---|---|
| ADR-024 決定2「このiPhoneでの猫写真の検出・一覧・基本Widget」を常時無料 | 一覧は無料のまま。ウィジェットの新しい1枚は体験後Plus（ADR-026の向きを確定） |
| ADR-024 決定2「自分で作れるまど1つ」 | **撤回**。まどを作るのはPlus（14日間の体験中は無料）。ADR-024 決定3「Plusで最大3つ」→ **5つ** |
| ADR-024 決定2「1まど2人」「1人4台」 | 画面改善案第3版 1-8 の決定（6人、3台）に従う。本ADRの範囲外 |
| ADR-024 決定5／Server ADR-025 の sponsorship「招待相手の送信は、まどを支えるPlus購入者の有効期間中」 | 形を変えて採用：**まどが続くかどうかは作った人のPlus**で決まり、止まったまどには誰からも新しい写真が届かない。招待された人自身の課金は求めない。sponsorship のコードをそのまま使うか作り直すかは実装計画で決める |
| ADR-025 決定4・5「FAMILY_SHARED を拒否」 | 受け入れる（決定4） |
| ADR-026「14日体験は仮説」 | 14日で確定。形は App Store のお試しオファー（アプリ側の日数管理は2026-10-20午後に撤回） |
| 課金と商品化の導線「年額9,800円を推奨」 | 最初は月額だけ |
| 現行LP・アプリのプレビュー表示「7日間無料（検討中）」「ツール3つは会員機能」 | 14日・ツール無料に置き換える |

変えないもの：写真の画質・暗号化・通知・安全機能・受信・ハートを課金軸にしない（ADR-024）。1参加者・1まどあたり1日5枚（Plusでも同じ）。既存利用者から機能を取り上げない（ADR-024 決定6）。物販の境界（ADR-024 決定7）。
