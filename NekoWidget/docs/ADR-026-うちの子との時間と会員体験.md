# ADR-026：うちの子との時間を育てる体験と会員サービス

2026-09-18。利用者が「この方針が私はイメージしやすいです。ここに向けて設計開発をすすめていきたい」と承認。方向を採用し、以下の順で実装する。価格、体験期間、容量、販売開始は未確定。既存利用者の機能を制限する変更は今回行わない。

## 目的と商品

写真を撮る日も、見返す日も、うちの子との毎日が手間なく大切な記録になっていく。今日のWidgetでの再会と、数年分の記憶の積み重ねを同じ体験につなぐ。一人で価値が成立し、猫登録・共有・日記入力・投稿を義務にしない。

事業としては、この体験を継続提供する会員サービスを主仮説とする。作品・印刷の購入、公開まどの閲覧者増加、猫個体識別研究の成功を成立条件にしない。愛情の強さを課金で測らず、継続して得られる価値を説明する。

## 無料と会員の境界（将来の商品設計）

| 対象 | 無料 | 会員 |
|---|---|---|
| 公式の猫を見る、招待先で送り合う・受け取る・ハート | 利用できる | 利用できる |
| 自分の写真・お気に入り、既に作った記録の閲覧・持ち出し | 利用できる | 利用できる |
| 自分の猫のWidget再発見、テーマ・成長・時期の自動整理 | 全体験を試せる期間を設計 | 継続利用できる |
| 写真と言葉・出来事を結び付け、記録を育てる | 体験期間と終了後の扱いを設計 | 継続利用できる |
| 家族の写真と言葉を一匹の記録に持ち寄る | 招待された記録へ参加 | 記録を作成・支援 |
| 同期・復元 | 過去記録へのアクセスと持ち出しを守る | 実装・容量・保持期間を確定した範囲を提供 |

有料は一種類、月払い・年払いを候補にする。一つの家族の記録を一人の契約で支え、猫の頭数を基本の課金軸にしない。招待家族に共有先への写真追加のための二重課金を求めない。別世帯の個人整理の権利とは区別する。

ADR-024の「個人Widget・基本自動アルバムを常時無料」「複数猫で課金」「作品中心の商品説明」は、この将来の商品設計へ改訂する。写真の画質、安全、基本受信・ハート、過去データの保全、販売前の実装確認、StoreKit基盤再利用の原則は維持する。旧価格980円/月・9,800円/年と14日体験は仮説であり、確定料金・確定契約ではない。

## 体験と情報設計

1. Widgetまたはアルバムで、うちの子の写真に出会う。
2. 共通の個別写真画面で、写真・実撮影日・本人が添えた記憶を見られる。
3. 任意で短い思い出を添える。入力しなくても鑑賞できる。猫を登録しなくても使える。
4. 同じ写真に再会すると、その言葉も戻ってくる。お気に入り解除・再スキャンで記録を消さない。
5. 次段階で既存アルバムから記録を日付・本人が指定した猫で見返す。新しいタブや毎日書く義務を追加しない。猫の選択は内容に入ってから行える既存設計を尊重する。

記録を写真に重ねて主役にしない。通常は写真の表示面積を守り、任意の入口と短い抜粋だけを出す。編集は写真の対象を固定した画面で行い、保存・取消・キーボードを閉じる手段を常に用意する。共有のひとことと個人記録は別物で、送信やWidgetへの自動露出はしない。

## 実装順と完了条件

| 順 | バッチ | 完了条件 |
|---|---|---|
| 1 / N25 | 個別写真に個人の思い出を添える | 登録・共有なしで作成/編集/削除できる。再起動後も同じ写真に結び付く。取消・書込失敗で内容を失わず、別写真への混入と共有への流出を防ぐ |
| 2 / N26 | 記録を見返す入口 | 既存アルバムから自分の記録に戻れる。写真0件、権限限定、写真消失でも記録を勝手に削除しない。写真IDだけに依存した将来復元の制約を扱う。原本/言葉を明示して持ち出せる |
| 3 / N27 | その猫らしい再発見 | Widget→個別写真→時期/テーマ/自分の記録がつながる。同日の安定性・猫の明示的所属・重複回避を維持し、AIが出来事を創作しない。実写真で楽しさを確認する |
| 4 / N28 | 家族で育てる記録 | 写真・言葉の著者、閲覧/編集/削除権限、共有解除後の扱いが明確。現在の一枚配送と共同の長期記録を混同しない。独立レビューと復元/解除の境界確認を行う |
| 5 / N29 | 保存・引き継ぎの約束 | 原本と参照・記録の復元対象を確定。端末紛失/機種変更/解約/容量上限/運営終了時の持ち出しと保管費を確認。無期限/無制限を根拠なく約束しない |
| 6 / N30 | 会員体験と採算 | 実際に体験した価値、自然な再訪、購入理由と非購入理由を確認。価格・体験期間・世帯権利・保管原価・集客費から採算を判断。短期好評を年間継続の証明としない |
| 7 / N31 | 販売準備 | 実装済みの提供範囲だけを表示し、既存β利用者の移行、権利復元、解約、請求猶予、オフラインを設計・検証。既存課金基盤を利用する。販売開始は別途依頼後 |

N25はこの長期計画の最初の縦断実装であり、年表・共同原本保管・クラウド復元の完成を意味しない。記録の同期や恒久保管が提供できると販売しない。

## N25のデータ境界

- 個人メモはApp専用の永続ファイルに保存し、スキャン結果・共有caption・WidgetManifest・診断ログへ混ぜない。
- キーはこの端末のPhotoKit ID。iPhone間で同じ写真を同定できるIDではない。猫プロフィールの有無や変更に左右されない。
- 旧データのない起動は空として開始。読めない/未知バージョンの既存ファイルは上書きしない。書き込み完了前に成功表示しない。
- 別写真への同時保存、写真送り中の編集、再起動、取消、削除、書込失敗を限定的に確認する。原本・お気に入り・猫の所属・配送状態は変更しない。
- 初版はこのiPhone内の記録である。アプリ削除や原本削除をまたぐ独立したアーカイブ・クラウド復元として案内しない。
- 手入力の記憶は再生成できないため、App専用領域の保護を維持しつつOSの利用者管理下のバックアップから意図的に除外しない。実際のバックアップはOS設定等に依存する。ファイルが戻っても別端末のPhotoKit IDへの再結合は未保証で、アプリの同期/引き継ぎ完成とは別である。

## 判断の根拠と未確認

Day Oneは基本の記録・閲覧を残してメディア/同期等を有料拡張し、解約後も記録へのアクセスを残す。みてねは受け手を含む家族体験と有料の継続機能を分ける。これらは商品設計の参考であり、本アプリの支払い需要・利益の証明ではない。

- https://dayoneapp.com/plans/
- https://mitene.us/premium

写真/Widgetが動くこと、思い出に価値を感じること、有料で継続することを別に判定する。売上、継続率、保管原価、利用者の記録入力負担はまだ実測できていない。一般公開、外部募集、課金開始、審査提出は本バッチに含めない。
