# ADR-023：季節の小さな映画

日付: 2026-08-28
状態: 実装・実機確認待ち
関連: [ADR-019](ADR-019-しおりと長期保管.md)、[情報設計](情報設計.md)

## 決定

「小さな便り」とは別に、完了した暦四半期の猫写真、動画、Live Photoから、端末内だけで「この季節の小さな映画」を組み立てる。月の便りは5〜7枚を自分の速さで読む体験、季節の映画は3か月の時間の流れを20〜30秒で感じる体験とし、片方をもう片方の再生版にしない。

映画は利用者が編集を始めなくても完成した状態で「今日」に現れる。写真だけの期間も対象にし、実動画またはLive Photoがあれば期間全体のバランスを崩さない範囲で自然に混ぜる。ただし静止画を無理にpan・zoomして動いているように装わず、短いcutまたはfadeでつなぐ。素材条件を満たさない場合は既存の月の便りだけを見せる。

## 採用する体験原則

他製品から借りるのは派手な演出ではなく、次の仕組みである。

- 完成品を自動で用意し、最初に編集作業を求めない
- 連写や短時間の似た場面をまとめ、同じ構図を続けない
- 期間の一部へ偏らず、撮影日と月を分散する
- 思い出に残した素材は加点するが、それだけで全体を占めさせない
- 見る前に確認画面や二つ目の再生ボタンを挟まない
- 編集可能範囲は後からの素材除外・差し替えに絞る

猫について「喜んでいる」「寂しそう」など、画像から確かめられない感情や物語を自動で付けない。「ふたり」「家族」も作品名へ固定せず、1人、多頭、友人との利用を狭めない。

### 調査根拠

- みてねは対象期間の写真・動画を、人物、公開範囲、コメント等で評価し、期間全体から偏らないよう自動選定している。動画は一部を切り出す。[みてねヘルプ：生成方法](https://help.family-album.com/hc/ja/articles/360038852633-1%E7%A7%92%E5%8B%95%E7%94%BB%E3%81%AF%E3%81%A9%E3%81%AE%E3%82%88%E3%81%86%E3%81%AB%E3%81%97%E3%81%A6%E4%BD%9C%E3%82%89%E3%82%8C%E3%82%8B%E3%81%AE%E3%81%A7%E3%81%99%E3%81%8B)
- 配信条件は対象写真・動画10点以上で、連写など撮影間隔の近い素材、極端に短い動画、破損素材等を除く。実動画だけを必須にはしていない。[みてねヘルプ：生成条件](https://help.family-album.com/hc/ja/articles/360038853413-1%E7%A7%92%E5%8B%95%E7%94%BB%E3%81%8C%E9%85%8D%E4%BF%A1%E3%81%95%E3%82%8C%E3%81%AA%E3%81%84%E3%81%AE%E3%81%A7%E3%81%99%E3%81%8C)
- 素材単体の評価だけでなく、撮影日時の分散と写真・動画比率を作品全体で整える点を採用する。[MIXI：みてねの生成技術](https://mixi.co.jp/sustainability/materiality/innovation/mitene/)
- 再生は利用者のタップから開始し、停止可能にし、元の縦横比を守る。[Apple Human Interface Guidelines：Playing video](https://developer.apple.com/design/human-interface-guidelines/playing-video)

## 生成条件

対象は直近の完了した暦四半期とし、次をすべて満たす場合だけ作品を出す。

- 近い場面をまとめた後に、異なる候補が10場面以上
- 6つ以上の撮影日に分散
- 四半期内の2か月以上に分散
- 完成作品は8〜14場面
- 実動画またはLive Photoがある場合は、一部の時期へ偏らない範囲で優先し、写真との比率を作品全体で整える

動画は端末内で取得できる代表フレームをVisionで確認し、猫を検出できたものだけを候補にする。写真、動画、解析結果をServerへ送らない。iCloudから自動ダウンロードして条件を水増しせず、取得できない素材はその回の候補から外す。生成失敗や素材不足で、月の便り、思い出、過去作品を削除しない。

写真の対象アルバムを利用者が選んでいる場合、動画も同じアルバム内だけを対象にする。選択済みアルバムを確認できないときは、全ライブラリへ自動で広げず作品を隠す。PhotoKitの動画・Live Photo取得は5秒で打ち切り、応答しない素材が作品全体を止めないようにする。

## 表示と操作

- 「今日」には完成した作品だけを、代表画像、期間、長さ、控えめな再生記号を持つ1枚のカードとして置く。
- カード全体のタップを再生意思とし、タップ後すぐ冒頭から再生する。
- 再生画面は黒を基調にし、原本の縦横比を守る。猫を切る強いcrop、ランダムなzoom、回転、派手なtransitionは使わない。
- 利用者は再生・一時停止・終了をいつでも操作できる。背景へ移ったら一時停止する。
- 「視差効果を減らす」が有効な場合、移動演出を使わず短いfadeまたはcutにする。
- 初期版は無音で統一する。短い原音と無音写真が交互に鳴る不連続を避け、音声やBGMは作品全体で制御できる段階まで追加しない。
- 最後は「この季節も、ここまで」とし、見返しを主操作にする。保存、共有、送信、購入を自動で行わない。

初期版には、BGM選択、filter、字幕、手動の並べ替え、切り出し位置、表示時間、書き出し、相手への送信、商品購入を含めない。端末内の鑑賞体験が成立した後に、必要性を実利用で判断する。

## 月の便り・思い出・将来の出口との関係

| 場所 | 役割 |
|---|---|
| 月の小さな便り | 完了した1か月を静止画で、自分の速さで読む |
| 季節の小さな映画 | 完了した3か月を、実際に動く素材を中心に短く見る |
| 思い出 | 利用者が明示的に残した写真を蓄積する |
| かたちにする／つくったもの | 将来、完成した作品や物理商品を見返す出口 |

映画の再生や自動選定だけで、素材を「思い出」へ追加しない。作品を将来「つくったもの」へ保存する場合も、元の写真・動画の保管契約とは分けて案内する。
